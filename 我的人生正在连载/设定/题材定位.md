# 题材定位 ·《我的人生，正在连载》

> 工作名（可改）：《我的人生，正在连载》／备选《读者别催更》《我的命，有人在写》《段评区》《这本书在写我》
> 上一版：《弹幕人生》（"人生被直播"版）—— 因撞《楚门的世界》已弃，改用"被写进小说"壳
> 项目形态：AI 漫剧（为漫剧而生；不写完整小说，直接"设定 → 分集 → 剧本"）
> 定位：都市 · 高概念 · 元设定 · 宿命感（喜剧底色 + 悬疑长线）
> 状态：待创作者确认

## 一句话故事

> 某天起，程屿眼前开始浮现「段评」——他的每一个选择、每一句没说出口的话，都被**实时写成一段文字**，旁边挂着读者的批注。这些批注能**剧透后面的章节**；而他，能**一个字一个字地，偷改自己的命**。

## 为什么这个壳能避开"楚门感"

- 楚门：**观众在"看"你**（公关问题）——我该怎么表现？
- 本作：**读者在"读"你**（宿命问题）——我是不是被写好了？我能不能改？
- 前者是"被围观"，后者是**"被书写"**——两种完全不同的心理体验，母题是**宿命 vs 改命**，不是"逃出摄影棚"

## 主角

- **程屿**（暂名，25 岁）：刚毕业两年、在不起眼岗位上耗着的普通青年
  - 人设立点：**一个连"作者"都只能勉强写出彩的平凡人**——反差是喜剧引擎
  - 性格：怂、嘴碎、心软；怕麻烦，但一旦发现"有人在读"，就格外想活得"好看一点"
  - 弱点（核心）：**太在乎读者的评价**。他会为了段评里的一句"这段太无聊了"，去做违心的事——这是全剧最主要的翻车来源
  - 标志动作：对着空气小声反驳（其实在跟段评较劲）、盯着视线边缘找"正文"

## 招牌机制一：段评 + 原文（能看、能读）

- **段评**：读者的批注，逐段出现，飘在视线边缘——可以吐槽、可以剧透、可以带节奏
- **原文**：他还能看见"正在被写的当下"——**动作、对话、甚至心理描写**，全被写成了字
  - 最细思极恐的一处：**原文里的心理描写，有时比他自己想的还准**——他到底了解自己，还是"作者"更了解他？

## 招牌机制二：改稿权（独家金手指）

> 他能"抢笔"——在原文上**改字**。改一个字，人生就真的变。

- **代价（关键）**：改一处，别处的"剧情"会塌——**作者会"打补丁"**，把世界强行纠正回来
- **越改越不像自己**：改得越多，他越靠近"读者想要的那个角色"，而不是他自己
- **有"更新节奏"**：他能感觉到有的日子是"高潮章"、有的是"过渡章"（元梗：这一章是来水字数的）

## 金手指分级（6 层）

| 层 | 能力 | 剧作作用 |
|---|---|---|
| 1 | 被动看见段评（读者对自己的吐槽） | 喜剧 + 破题 |
| 2 | 能看见"原文"——读到正在被写的当下 | 元设定核心 |
| 3 | 能分辨"剧透式批注"和"读者瞎猜" | 悬念启动 |
| 4 | 能看见"伏笔"——人生里那些早就被埋下的线 | 长线钩子 |
| 5 | 能改字（抢笔改稿，有巨大代价） | 招牌爽点 |
| 6 | 能看见"作者"——那个正在写他的人 | 终极揭晓 |

## 代价与限制（防止万能）

1. **段评是读者的，会错**：批注不是预言，是一群人的解读——有的对、有的错、有人故意带偏。信错就翻车
2. **改字必崩**：改一处 → 作者打补丁圆回来 → 有时越圆越糟
3. **越改越假**：改到最后，"程屿"变成了读者喜欢的角色，而不是他自己
4. **作者有目的**：他写他，不是随手写写

## 主线：是谁在写我（三段式）

- **第一段（1–8 集）· 破**：段评出现 → 读到原文 → 确认能剧透 → 也发现"读者会猜错、会带节奏"（第一次被坑）→ 结尾抛钩：**这本书里，不止他一个"被写的角色"**
- **第二段（9–18 集）· 查与改**：他开始改稿，尝到甜头也吃到大亏；发现书里**别的角色也在反抗剧情**（有配角想抢他的戏份）→ 查"作者为什么写这本书"
- **第三段（19–24 集）· 揭**：三层——① 这本书是**写来给"另一个世界"看的**（有人把真实的人生写成小说，供人阅读）；② 而这个"作者"，**自己也正被更高的存在写着**（套娃）；③ 终极：他抢到笔，**第一次自己写了一句话**——却发现"写自己"和"活自己"是两回事，最终落回母题：**夺回自己人生的叙事权**

> 第一季只揭到第 1–2 层，第 3 层留给下一季。

## 单元结构（每集怎么长出来）

每一集 = **一个现实困境 × 一种"段评/原文"玩法 × 一次"信不信、改不改"的抉择**

- 玩法轮换：吐槽（笑）→ 剧透（悬）→ 打补丁（坑）→ 催更/骂作者（情绪）→ 改字（爽）→ 断更式"集体沉默"（恐惧）
- 主线每集推进一小格（段评里多一条"不该出现的话"）
- 每集结尾留一个"段评钩"——最后一行段评总是话说到一半

## AI 漫剧适配度

| 维度 | 评估 |
|---|---|
| 场景成本 | ★★★★★ 全是日常场景（公司/出租屋/地铁/奶茶店） |
| 特效需求 | ★ 段评/原文=文字层，纯后期叠加，几乎零特效 |
| 角色一致性 | ★★★★ 人物少、造型日常 |
| 分集可持续 | ★★★★★ "一集一种玩法"天然分集 + 主线悬念兜底 |
| 画风建议 | 写实向国漫风。**双重字体做视觉签名**：原文用优雅衬线（像书页），段评用活泼网感字体（像弹幕） |
| 声音 | 强项：段评可配气声/机械音；日常对白为主，配音可控 |

## 风险与对策

1. **元设定有理解门槛** → 前 3 集用喜剧 + 具象画面破题，第一条段评就是笑点，别急着讲设定
2. **别拍成"旁白剧"** → 硬规定：段评/原文**必须驱动剧情**，不能只做解说
3. **"谁是作者"别吊太久** → 第一季必须揭到"这是一本写来给另一个世界看的实录"
4. **"改字"别用滥** → 每集最多一次，且必须有代价、有反噬

## 已定稿（创作者确认）

1. **主角职业**：普通小职员 —— 程屿，25 岁，毕业后在小公司做最没存在感的岗位
2. **段评的声音**：**可见 + 可听**（段评有语气、可以七嘴八舌，是"热闹的读者"）；**原文保持无声**——冰冷的文字被写下来，形成"热闹的评论 vs 无声的书写"对比
3. **基调配比**：喜剧 6 : 悬疑 4
4. **题材频道**：男频向
