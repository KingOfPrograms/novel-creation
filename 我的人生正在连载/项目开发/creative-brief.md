# 短剧创作简报 ·《我的人生，正在连载》

> 依据：`设定/题材定位.md`（创作者已定稿：主角=普通小职员；段评可见+可听、原文无声；喜剧6:悬疑4；男频向）
> 版本：v1（2026-10-10）｜创作者状态：待接受

## 1. 项目意图

- **暂定名**：《我的人生，正在连载》（备选《读者别催更》《段评区》）
- **一句原始想法**：创作者——"一开始就为漫剧写的新项目，要一开头就能吸引人的新颖设定"
- **这次要完成的工作**：系列开发 + 第一季分集规划（原创新项目，非改编）
- **来源材料**：无原著；本简报与 `story-engine.md` 是第一手事实来源
- **不可更改的来源事实**（创作者已定稿，作为基准）：
  - 主角能看见「段评」（读者批注，**可听**）与「原文」（正在被写的当下文字，**无声**）→ 全程可见载体为"屏幕/空气上的文字 + 段评语气声"
  - 主角掌握「改稿权」——在原文上**改字**可改变现实（代价见引擎 DEV 条款）
  - 段评**半真半假**、会剧透也会误述、能被带节奏（不是可靠预言）
  - 母题 = **宿命 vs 改命**；核心悬念 = 是谁在写我
  - 规避：**不做**《楚门的世界》式"逃出摄影棚"，改为"被书写/夺回叙事权"
- **允许改编/探索的范围**：人物关系网、单元事件、"作者/观众"层的揭晓节奏、第一季结尾落点
- **原著没有、本轮新增的内容**：全部为原创（无原著），不涉及新增登记

## 2. 创作者契约

- **希望观众反复获得的体验**：① 喜剧错位（"被围观的尴尬"）② 信息差爽感（靠段评/改稿翻盘或翻车）③ 悬疑钩子（谁在写我）
- **不希望作品变成什么**：不是"读心/预知"爽文（段评不可靠）；不是楚门式逃亡；不是靠旁白解说的"有声旁白剧"
- **主题张力**：**被写好的人生（安全、讨喜）↔ 自己活出来的人生（真实、可能不讨喜）**
- **语气与尺度**：轻喜剧打底、悬疑收口；都市日常；无血腥无色情、无政治敏感、不依赖大场面
- **结局承诺或禁区**：第一季揭到**第二层**——"这是一本写给另一个世界看的实录"+"作者自己也被更高的存在写着"；第三层（他不是第一个主角 / 上一季主角正坐在读者席）留作下一季引线
- **内容边界**：职场与都市日常为主；段评文案须自洽、可读；不消费真实社会事件

## 3. 形式与制作边界

- **主要语言**：zh-CN
- **画幅/观看场景**：**16:9 横屏**（延续创作者对横屏漫剧的偏好）；手机横屏/网页漫剧
- **单集与系列形式**：第一季 **24 集**，单集目标 **约 240 秒（4 分钟）**
- **可用角色与场景规模**：核心 5 人（程屿、马腾、赵敏、苏晚、顾行）；常驻场景约 5 处（出租屋、公司、地铁/通勤、奶茶店、天桥/江边）
- **难以承受的制作元素**：大场面、爆炸、复杂特效、照片级写实人脸（采用**写实向国漫**：保留写实比例与光影，以风格化笔触规避恐怖谷）
- **必须保留的视觉/声音特征**：
  - **原文**：优雅衬线体、冷色、**无声**（像书页被写下来）
  - **段评**：活泼网感字体、暖色/杂色、**有语气声**（七嘴八舌）
  - 两者同框时形成"**热闹的评论 vs 无声的书写**"对比——本片视觉签名

## 4. 戏剧承诺（工作版）

- **焦点人物**：程屿（25 岁，普通小职员）
- **当前追求**：搞清楚自己为什么能看见"原文"和段评，并**守住自己的生活不被"写"坏**
- **昂贵阻力**：那个"作者"及其背后的规则——他能**打补丁**纠回任何改动；还有被段评带着走的读者情绪
- **独特矛盾**：他用"改字"修正生活 → 作者越要打补丁 → **改得越多，"程屿"越像读者想要的角色，离真实的自己越远**
- **反复回报**：每集一次"信/不信、改/不改"的选择 + 一次信息差翻盘或翻车
- **终止性转变**：当他**夺回"叙述权"**（能自己写自己的一句话），旧引擎失效

**一句工作陈述**：

一个普通青年发现人生正被实时写成一本小说、还能看见读者批注，他想用"改字"把日子过好，却每次都招来作者的"补丁"——他必须慢慢明白，真正要抢回来的不是"写得更好"，是"自己写"。

## 5. 方向候选与选择

### 候选 A：被写进小说（选定）
- 主角惯常策略：靠段评/原文获取信息、用改字修正生活
- 主要对抗机制：作者打补丁 + 读者误导 + 人设漂移
- 退出成本：一改就招补丁，越改越不像自己
- 反复回报：信息差翻盘/翻车 + 喜剧错位
- 核心代价：真实自我被"角色化"
- 引擎终止条件：夺回叙述权
- 主要制作负担：低（场景日常、文字层零特效）
- 擅长提供：元设定话题、喜剧、悬疑
- 会牺牲：纯写实质感（需接受"元设定"门槛）

## 6. 核心人物与关系压力

### 程屿
- 当前目标：弄明白"是谁在写我"，并保住自己的生活不被写坏
- 保护对象：母亲留给他的旧出租屋、室友马腾的信任、自己"还是自己"这件事
- 被捍卫的信念："日子是我自己的，凭什么被别人写"
- 前史成因：从小普通、不被注意，习惯了"活得不起眼才安全"——所以一旦发现"有人在读"，反而更想活得"好看"
- 惯常策略：先看段评再决定怎么做（先作弊、后补课）
- 策略盲区与代价：**太在乎评价**；信错段评就翻车；改字越改越假
- 可用筹码：能看段评/原文；后期掌握改字
- 底线与可能越线条件：不拿别人的命去改自己的日子；但会为救马腾越线（EP012）
- 可能改变其策略的事实：发现"作者也被写着"

### 马腾（室友，喜剧担当）
- 当前目标：混日子、谈恋爱、蹭程屿的饭
- 被捍卫的信念："我哥们儿程屿只是运气差，不是没本事"
- 与程屿关系：程屿唯一无条件信任他的人——**程屿的"真实性"锚点**（改字后马腾对他的记忆会缺一块，制造最痛的代价）

### 赵敏（女上司）
- 当前目标：业绩与自保
- 与程屿关系：职场压力源；程屿靠段评在她面前翻盘，也因依赖段评而人设漂移

### 苏晚（前女友）
- 当前目标：（暂）：过好自己的新生活
- 与程屿关系：程屿想用改字挽回她，被顾行警告"改出来的感情是假的"——**主题试金石**

### 顾行（第二段登场，"同类"/镜像）
- 当前目标：不想被"写没"
- 前史：一个"被作者写死过、又被读者救活"的角色（bug 存在）
- 与程屿关系：从对手/警惕→结盟→（EP022）做出牺牲；他是程屿的"未来警示"

## 7. 叙事切入窗口与前史储备

- **故事切入前已经运行的压力**：程屿的平庸日常——加班、被忽视、暗恋已散、室友蹭饭
- **叙事切入窗口**：**段评第一次出现的那一刻**（凌晨加班后回出租屋）
- **第 1 集入口候选**：
  1. **时序入口**：从他普通的一天开始（上班→加班→回家）→ 开场第一帧：挤满人的地铁里，程屿面无表情刷手机；问题："一个这么普通的人，值得被拍一集吗？"｜整集收益：中（要等到中段才有钩子）
  2. **收益入口（选定）**：直接从"段评出现"开始——开场第一帧：深夜出租屋，一行字浮在空气里：「这一幕太真实了，看得我喘不过气」；问题："这行字是谁写的、写给谁看？"｜整集收益：强（段评=钩子、剧透应验=兑现）
  3. **冷开入口**：先放后文 EP005 的"改字崩塌"最后一拍（他改了一个字，世界瞬间错位、作者补丁先兆），再回到段评初现｜问题："他改了什么字，为什么世界会崩？"
- **选定**：**收益入口（2）为主，结尾埋冷开式危机感**——开场画面自己就是钩子、观众收益强，且能在集尾交代身份、危机与"想搞明白"的目标
- **为什么不更早/更晚**：更早是"普通人的日常"，观众几秒划走；更晚则丢掉"他第一次被剧透"的新鲜冲击
- **开场可见证据**：段评文字浮在空气里、只有他能看见（旁人无反应）；剧透应验（水杯真的洒了）
- **观众现在必须知道**：程屿是谁、他平凡、他能看见别人看不见的"字"、他害怕又好奇
- **观众暂时不需要知道**：原文的系统规则、改字、作者、其他角色——留给后续
