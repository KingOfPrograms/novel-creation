# 题材定位 ·《门口的灯》

> 工作名（可改）：《门口的灯》／备选《还热着》《深夜的那碗面》
> 项目形态：AI 漫剧（为漫剧而生，不写完整小说；直接"设定 → 分集 → 剧本"）
> 基调：暖愈向（市井 · 小人物 · 单元剧 · 一条主线悬念）
> 参考坐标：《深夜食堂》的容器结构 +《我不是药神》的"小人物做大事"内核 +《请回答》系列的时代温度
> 状态：待创作者确认（容器/设定/主打线性均可改）

## 一句话故事

> 医院后门那条巷子里，有一间只在深夜亮灯的小馆。老板从不问客人来历，只把一碗"刚好是他此刻最需要的那口热"放到他面前——因为他自己，也正守着一碗永远等不到人的汤。

## 定位与基调

- **类型**：都市 · 市井 · 暖愈 · 单元剧（每集一位客人 = 一个故事）+ 一条贯穿的老板身世主线
- **情绪承诺**：看完每一集，胸口暖一下；看完一季，记得住人
- **不做什么**：不做奇观、不做大场面、不做无脑爽、不贩卖苦情。沉重只做背景，**暖意才是主角**
- **受众**：全年龄偏成人向（打工人、异乡人、为人父母/子女者最能共鸣）

## 为什么选这个容器（选题逻辑）

暖愈向 + AI 漫剧的三个硬约束：**场景少、能复用、靠情绪不靠特效**。

- 一间深夜小馆 = **一个主场景反复用**，夜戏光影出氛围、成本极低
- 食物 = 天然的视觉符号（热气、汤面、灯光），AI 生成友好
- "一位客人一集" = 单元结构，**分集天然成立**，追更不累
- 医院门口 = 把人一生最脆弱、最真实的时刻集中到一处，情绪浓度高，且**不需要废土废墟那种昂贵置景**

## 容器与场景

- **主场景：门口的灯（深夜小馆）**——医院后门一条少有人走的老巷里；白天卷帘拉下、像歇业，深夜灯亮
  - 一进门是几张旧木桌、一面贴满客人随手留言和便签的墙、一个永远温着汤的灶台
  - 招牌菜就一样：一碗面（外加几样家常小菜），价钱便宜到不像话
- **副场景**：巷口便利店、医院后门、深夜街道（车灯、雨、路灯），均为**低成本可复用**夜景
- **时间**：多在夜里 22:00–凌晨 4:00；"深夜"既是物理设定，也是情绪设定

## 主角

- **暂名"陆平"**（可改）：小馆老板，四十上下，寡言，手上总有活
  - **表面**：一个普通的、开了间不赚钱小馆的中年人
  - **底色**：他"会看人"——看一眼，就知道一个人此刻缺的是什么。这份"会看人"从何而来，是第一季最大的悬念
  - **标志动作**：不问来历，只问一句"吃面还是吃饭"；上菜前总要吹一吹碗沿的热气
  - **弱点**：他替所有人热着饭，唯独自己**从不坐下吃一口**——他有一道永远做不出来、也永远等不到的"味道"
- **配角/群像**（每集新客 + 少数常客）：
  - 常客：医院夜班护士、巷口便利店小姑娘、跑夜车的出租车司机、总在凌晨来坐一会儿的退休老人
  - 每集新客：各式被生活绊住的人（异乡考生、送外卖的父亲、被裁的中年人、备考医生的年轻人、失独老人……）

## 招牌设定（软异能，暖愈向的分寸）

> 老板下的面，**刚好是客人此刻最需要的那一口味道**——也许是老家灶台的味，也许是妈妈没来得及教的那口汤。

- **分寸感（重要）**：这一条写成**"介于现实与奇迹之间"**——可以理解成他的眼力与手艺，也可以理解成一点点温柔的奇迹。**永远不点破**（保留《深夜食堂》式的留白）
- **它的作用**：给每一集一个**招牌高光**（汤面上桌那一刻），给每集一个**情绪爆点**，形成本剧的"视觉 + 情绪签名"
- **它的限制**：他**从不为客人解释**，也从不用它做交易、不做"治愈包治百病"的神棍——他只提供一顿饭、一个夜晚、一次被"看见"

## 代价与限制（防止设定滑向万能）

1. 他只**能做饭**，不能解决客人的实际问题（钱、病、婚姻、前途都不归他管）——他只能让人"喘一口气"
2. 他**给自己做不出那口味道**（对应他失去的人），这条贯穿全季
3. 灯**只在他想开、也只在"对的人"路过时亮**——这层暧昧的"选择性"是主线的伏笔之一
4. 小馆**迟早保不住**（拆迁/房租/身体）——这是"小人物做大事"的压力源：他要为一个"不赚钱的小破店"扛下去

## 主线三段式（小人物做大事）

- **第一段（1–8 集）· 立**：介绍小馆与规矩，一位位客人登场，埋三个钩子——① 他为何开这店 ② 灶台边那张旧照片上的女人是谁 ③ 他每天多煮的一碗面，是留给谁的
- **第二段（9–20 集）· 破**：小馆面临关闭（拆迁/房东/他身体出了问题），常客们第一次反过来想为他做点什么；同时，一个"知道这条巷子旧事"的人出现，逼出他尘封的过去
- **第三段（21–24 集）· 合**：他等了很多年的那个人/那件事有了回音；他终于为自己煮了一碗面——救赎与放下。小馆是否保住**不是重点**，"这座城市的深夜从此多了一盏灯"才是重点

## 单元结构（每集怎么长出来）

每一集 = **一位深夜来客 + 一道"他需要的味道" + 一次被看见 + 一条主线细微推进**

- 结构模板：① 深夜，有人走进巷子（他是谁、发生什么）② 老板不问，只做饭 ③ 招牌高光：那口"刚好对味"的热 ④ 客人卸下防备（或没卸，也没关系）⑤ 天亮，人走了，店里的灯还亮着 ⑥ 片尾：主线推进一小格（旧照片、多煮的那碗、巷子外的某个人影）

## AI 漫剧适配度评估

| 维度 | 评估 |
|---|---|
| 场景成本 | ★★★★★ 主场景一间店反复用，夜戏出氛围 |
| 角色一致性 | ★★★★ 人物少、造型固定、无变身，一致性压力小 |
| 特效需求 | ★ 几乎为零（热气/灯光/雨，均低成本） |
| 分集可持续 | ★★★★★ "一位客人一集"天然单元，主线悬念兜底 |
| 画风建议 | **2D 国漫 / 手绘暖色**（写实易掉恐怖谷，风格化最适合本片调性） |
| 声音设计 | 强项：市井环境音 + 灶火 + 一句"吃面还是吃饭"；对白为主、配音可控 |

## 风险与对策

1. **撞"深夜食堂"既视感** → 对策：**医院后门 + 味觉招牌设定 + 强主角身世主线**三件套拉开差异；不写"食堂"写"小馆"，不写"食客"写"深夜路过的人"
2. **单元剧容易散、观众留不住** → 对策：主线钩子（旧照片 + 多煮的碗 + 老板的过去）从**第 1 集**就埋，每集只推一小格
3. **暖愈向"不爆量"** → 对策：接受它是"慢热 + 口碑"型；用**每集一个情绪爆点**（招牌高光）保证单集可传播（切片短视频）
4. **医院背景过重** → 对策：医院只在"背景"里，正面写小馆；沉重点到为止，**每集必须落回暖**
