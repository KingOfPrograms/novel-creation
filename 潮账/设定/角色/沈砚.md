# 沈砚

## 一、三层身份

**第一层（他以为的自己）**
沈砚，三十岁，灾前在城东一栋写字楼的十七层做审计。审过一家物流公司的运输费，三百二十万拆成四十七张发票，一张一张对出时间差。也签过一份他不该签的报告，第二天公司爆雷，六百多个工人的工资没了着落，他在会议室里把责任推给一个来三个月的小孩，推得很干净。

**第二层（档案里的自己）**
联治局配给处三级核算员，编号 PB-0731。职责是随队核账：清点回收物资、封箱、编号、在任务单上签字。不会开枪，不编入战斗序列，队里管这种人叫"拎簿子的"。

**第三层（他自己也不知道的）**
调潮计划第七号的记忆容器。环陆抽走第七号的记忆，装进一个不相干的会计身上，因为需要一个干净、不会被追查的身份，把这份记忆带出潮区。

他自己不知道这一层。读者也不知道，直到第四卷。

## 二、能力

**审计（主业，全书爽点来源）**
复式记账、抽样核对、追单号、看时间差。他能从一本配给簿里看出谁在吃空饷、哪批货没到、哪个数是补上去的。

写作纪律：他的每一次判断都必须有具体依据——一张单子、一个编号、一处改动痕迹。不许"他忽然觉得不对"。

**账与实物必须对得上（性格即能力）**
他看见一个数，会去找对应的东西。账簿上写着光伏板去年十一月拆走了，编号 041 到 052，那他抬头看见有块板在反光，第一反应不是"有人在上面"，是"这个数错了"。他的预警永远从错账开始。

这是全书最重要的能力设定：**他不是聪明，他是不能忍。**

**不属于他的记忆（暗线）**
他记得潮区里的路，认得一个仓库的门轴声，记得一张脸、一句自己没说过的话。全是画面，没有名字。

原因：记忆是别人的，而且是残缺的。第七号的记忆在容器里会漏。

写作纪律：这段记忆只能给"画面 + 触感"，不能给答案，不能给完整对白。他一辈子想不起那个人的名字。

**语言与体能**
不会打，跑不快，肺不好（小时候的病，不是潮）。涂层服穿上三层，走两公里就喘。

## 三、弱点

1. **他签过字。** 灾前那份报告是他签的，他这辈子最怕的不是死，是再签一次同样干净的字。
2. **他推卸过责任，而且推得很成功。** 这件事一直在。他后来所有的"不能忍"，一半是在还这个债。
3. **他不会说服人。** 他知道的比别人多，但说出来的方式永远像在挑刺。第一次警告失败，就是因为他说得像在指责。
4. **他不是任何一方的人。** 联治局觉得他是外人，守潮人觉得他是官面上的人。他没有阵营，所以每一次选择都只能自己扛。

## 四、动机

**表层**：活下去，别被派进潮区第二次。

**中层**：把那本账对平。他不接受"对不上"这件事存在。所有的账最后都要有一个人签，他想做那个把最后一笔看清楚的人。

**深层**：他需要一个机会，证明自己不是那个在会议室里把责任推给小孩的人。

**终局**：当他发现自己的记忆是别人的，他必须回答一个问题——**一个由别人记忆拼成的人，签的字算不算数。** 他的答案是算，因为签字的那一刻是他自己在场。

## 五、金手指规则（写作硬约束）

1. **他的预判只能来自账**。任何"他早就知道"的段落，必须能在前文找到一条线索：一张单、一个编号、一处涂改。
2. **记忆碎片只给画面，不给名字**。所有"他记得那个人"的段落，都必须停在"想不起叫什么"。
3. **他改一次事，记忆掉一层**。这条跟潮芯的调潮代价共用一套设定。他每救一个人，就会更不知道自己是谁。
4. **他永远说不出内鬼的名字**，只指得出"这一笔不对"。这也是他必须去查账、而不能直接举报的原因。
5. **他不能靠武力解决任何问题**。他的解法只有三种：让规则杀人、让别人动手、让自己成为别人需要的人。

## 六、外形与习惯

- 瘦，手指长，指甲修得很短（核账的职业病）。
- 穿三层涂层服，外层左袖有一道补过的裂口，用不同颜色的胶带粘的。
- 随身三件：配给簿、短铅笔、两枚铅封。铅笔削得极短，短到要捏着写。
- 说谎的时候会低头看自己的手。
- 左手虎口有一道旧疤。这道疤不是他的。
