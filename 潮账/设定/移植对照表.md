# 移植对照表：三角洲行动 → 《潮账》

## 一、一句话说清

《三角洲行动》值钱的不是枪械和地图，是三层结构：

1. **三方咬合**：技术垄断的跨国集团 / 名义正义但内部腐败的超国家组织 / 被剥夺后分裂成军阀的本地武装
2. **一个能改写权力格局的核心技术**（曼德尔砖），加上拿人体做的不道德实验（Relink）
3. **一套风险经济**：进图、搜刮、抢在关门之前撤离

这三层全部可移植，而且与"军事"无关。不可移植的是皮：地图布局、枪械型号、干员技能。

## 二、逐项映射

| 三角洲原设定 | 《潮账》设定 | 移植时改了什么 |
|---|---|---|
| 阿萨拉（北非虚构国家） | **潮区**（灾前中国东南沿海一座地级市，被白潮淹了十六年） | 从"异国战区"改成"自己国家废掉的一块地"，痛感更近 |
| 零号大坝 | **三号高地**（旧城供水枢纽，现在被守潮人占着） | 地形功能保留：单点、易守、有闸、有水位 |
| 哈夫克集团 | **环陆集团** | 从科技财团改成**气候工程公司**：白潮就是它造的，灾后靠卖滤芯活着 |
| 曼德尔砖 | **潮芯**（七个植入了调潮算法的活人） | 从"机器"改成"人"，是全书最重要的一改 |
| Relink 脑机实验 | **调潮计划** | 用活人当调节器，因为机器会被白潮锈蚀；每调一次，记忆掉一层 |
| GTI（全球威胁倡议组织） | **联治局**（联合治理局） | 各国残部拼的临时政府，管配给、管准入、管"回收" |
| GTI 高层内鬼 | **韩敬**（联治局回收处处长，同时是环陆的外部顾问） | 双重身份保留，且比原版更毒：他替两边办事，两边都以为他忠诚 |
| 阿萨拉卫队 | **守潮人** | 灾后社区自卫队分裂成的割据武装，占高地、收路引、卖假滤芯 |
| 雷斯（占长弓溪谷） | **陈九**（占三号高地，父亲死于灾变第一夜） | 保留"为父守一块地"的动机内核 |
| 赛伊德 / 德穆兰 / 渡鸦 | 暂不映射 | 留在二、三卷再落，不急着塞 |
| 红狼 | **郑野**（外号野狗，联治局卫戍队） | 保留"动手的人 + 最早怀疑主角的人"这个功能位 |
| 干员技能 | 潮民的土办法：听潮、辨蜡、走暗渠、认封条 | 技能改成**经验**，不给超能力 |
| 搜打撤 | **进城—搜刮—赶在涨潮前从闸门撤出** | 机制内核完全保留，外壳换成潮汐 |
| 保险箱 | **铅封箱**（封条有编号，开了就作废） | 铅封是硬规则：值钱的东西必须当众封、当众签 |
| 撤离点 | 船闸 / 渡口 / 地铁口 | 每个点都有各自的"关门方式" |
| 背包容量 | 涂层服负重 + 跑不动的物理限制 | 拿多了会死，比任何数值都直观 |
| 主角记得游戏剧情 | **现代审计思维 + 一段不属于自己的记忆碎片** | 见第四节，这是全书的换心手术 |

## 三、必须死守的三条

1. **三方都不干净。** 环陆是罪犯也是唯一在维持秩序的人；联治局在救人也在倒卖；守潮人在自保也在收买路钱。任何一方写成纯反派，这书的骨头就软了。
2. **麦高芬能改写格局。** 潮芯不是一件值钱的东西，是"谁拿到谁就能造出永久安全区"——等于重建国家。所以三方动机必须都成立（见《三方势力》第四节）。
3. **撤离有硬时限。** 潮一涨，路就没了。所有紧张感都压在这根时钟上，不能松。

## 四、必须丢掉的三样

1. **"他玩过这款游戏"这个前提。** 换世界之后这条当场失效，留着就是自相矛盾。
2. **现代军事术语。** 枪还在（灾前军警遗留，守潮人也用），但"战术动作、弹道、编制"这套词退到背景，不要成为叙事腔调。
3. **地图复刻式的场景描写。** 别再写"行政楼三层东侧库房"这种游戏点位的精确感，改成真实废墟的逻辑：哪面墙塌了、水从哪进来、电从哪来。

## 五、金手指换心手术（最关键的一处）

原版：他记得游戏剧情，所以能预判。

新版拆成三层，一层比一层狠：

| 层 | 能力 | 用在哪 |
|---|---|---|
| 第一层（明面） | **审计**。复式记账、抽样核对、追单号。能从一本配给簿里看出谁在吃空饷、哪批货没到、哪个数对不上 | 全书爽点主力。不靠先知，靠专业碾压 |
| 第二层（半明） | **账与实物对不上就一定要对上**。他的预警永远来自"账面和现场不一致" | 第 1 章的第一次预警就是靠这个，不是靠玄学 |
| 第三层（暗线） | **一段不属于他的记忆**。他记得潮区里的路、记得一张脸、记得一句自己没说过的话。只有画面，没有名字 | 悬念引擎。他为什么会有别人的记忆？答案在潮芯身上 |

第三层的解释（第四卷回收）：**他是调潮计划第七号实验体的记忆容器。** 环陆抽出第七号的记忆，装进一个不相干的会计身上——因为需要一个干净、不会被追查的身份带着这份记忆走出潮区。

这一改同时解决了四件事：

- 金手指不再依赖"玩过游戏"
- 记忆漂移有了物理原因（容器不稳，记忆在漏）
- "他连自己是谁都证明不了"变成主线
- 麦高芬（潮芯）与主角（第七号的容器）焊在一起，终局不需要另设敌人

## 六、命名对照速查

- 灾变：**白潮**（2031，环陆计划第七次播撒失控）
- 当下：**2047 年**，灾后十六年
- 计量：**潮历**（朔望两日大潮，浓度暴涨）；**潮尺**（涂白蜡的测潮标杆，蜡面变色即潮位）
- 组织：环陆集团 / 联治局（回收处、配给处、准入处）/ 守潮人（渡口、灰帮、散股）
- 人要：韩敬（内鬼）、温季同（调潮组负责人）、郑野（野狗）、陈九（三号高地）、雷振（老雷，回收队队长）
- 物资：D-17 菌剂、滤芯、抗蚀涂层、铅封箱、配给券、盐
- 主角：**沈砚**，编号 PB-0731，三级核算员（原名陆沉，改名的理由是"沈砚"这三个字在末世不违和，且"砚"有磨的意思，与他反复核对的动作相合；如想保留陆沉也成立，只需全篇替换）
