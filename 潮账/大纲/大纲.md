# 五卷总纲

**书名**：潮账
**体量**：五卷，约 120 万字
**类型**：末世 / 灾变 / 谍战 / 职业流（审计）
**一句话**：灾后十六年，一个不会打枪的核算员被塞进回收队进城核账，第一次任务他就发现任务单上有一栏被人涂掉了——那一栏写着"活体，单件"。

## 卷一《退潮》（1-60 章）

- 时间：进城那一天起，二十一天
- 起点：配给处三级核算员，随队核账，连枪都没摸过
- 终点：被调入回收处，手里有第一份对不上的账，身上有第一个因他而死的人
- 核心事件：回收队七组进三号高地取 D-17 菌剂，遇伏，九人进去六人出来；他靠一条"光伏板账目不符"预警了伏击，但只救下一半人
- 卷末兑现：他从复写纸背面抠出"活体，单件"，并发现船吃水不对——他们带回来的东西比清单多一个人

## 卷二《铅封》（61-120 章）

- 核心事件：他追"第四项"的去向，顺着铅封编号查到一批被封了又拆、拆了又封的箱子
- 中点反转：破格提拔他的正是韩敬，理由是"你看账的眼神，跟我认识的一个人很像"
- 第一次设局：用封条编号做局，让内鬼的人自己动手拆了一箱不该拆的东西
- 代价：郑野被派去一次"例行护送"，中了埋伏，伤了两个兵
- 卷末：他被停职审查，证据是他自己签过字的一份验收单

## 卷三《灰帮》（121-180 章）

- 核心事件：为了查"活体"是什么，他必须进潮区深处，找灰帮买消息
- 他第一次见到守潮人的世界：高地一年比一年小，潮每年往上爬一格
- 陈九的账本：这个"军阀"的账比联治局的干净
- 卷末：他知道了潮芯是什么——不是机器，是七个还活着的人

## 卷四《调潮》（181-240 章）

- 核心事件：进环陆的塔，见到温季同
- 真相第一层：调潮计划在编一人，失踪两人，死亡四人（数字是假的）
- 真相第二层：他左手虎口那道疤不是他的；他记得的路，是别人走出来的
- 卷末：他拿到第一份可以呈堂的证据，当场被调包；替死的是他最不想连累的那个人

## 卷五《潮芯》（241-300 章）

- 三方同时动手抢潮芯：环陆要销毁，联治局要收复城市，守潮人要换十年的滤芯
- 他必须回答的只有一个问题：一个由别人记忆拼成的人，签的字算不算数
- 终局：他把潮芯交出去的方式，让三方谁都没拿到，也谁都没失去——他做了一份三方都能签的账
- 最后一笔：他在账本最后一页签上自己的名字，日期写的是他真正醒来的那一天

## 数字线

3（他记得会死的人） → 0（他救下的） → 3（为他而死的人） → 7（七个调潮人） → 1（他自己）

## 三条不能破的线

1. 他永远靠账解决问题，不靠武力，不靠突变
2. 三方都不干净，任何一方写成纯反派，这本书就软了
3. 记忆碎片只给画面不给名字，直到第四卷
