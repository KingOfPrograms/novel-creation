# 第一次，认真听她说话

图书馆里，几百条心声，照例往林川脑子里钻。

有人在焦虑考研，心里把专业书翻了又翻；有人在盘算晚饭吃什么；有人盯着对面的异性发呆，脑子里全是些乱七八糟的念头；还有人看两行书就摸一次手机，心里骂自己怎么这么没定力。

吵归吵，林川早习惯了。

唯独靠窗那一小片，安安静静，一点声音都没有。

苏念在那儿。

最近这阵子，林川来图书馆来得格外勤。他自己心里清楚，这里头有一半，是因为苏念常来。可他不愿意承认，只当自己是突然想学习了。

林川本来只想找个位子坐。可今天图书馆的人出奇地多，他抱着书转了一圈，愣是没找着空位。等他再抬头，就发现自己已经站在了苏念斜后方那排。

空着的位子，正好在她斜后方，隔着一排。

他犹豫片刻，还是坐下了。心说，自己只是碰巧走到这儿。

坐下之后，他习惯性地，把注意力往苏念那个方向，轻轻探了一下。

没有。

意料之中的死寂。这些天试了那么多次，他早该免疫了，可每次真的一片空白的时候，他心里还是会咯噔一下。

他收回注意力，逼自己把心思放回书上。来之前他还跟自己说好了，今天就老老实实看书，别再想那些有的没的。

可有些事，越想控制，越控制不住。他盯着书，一行字在眼前跳来跳去，跳着跳着，就变成了苏念的样子。

他坐不住了，回头飞快地扫了一眼。

苏念低着头，笔在纸上沙沙地写，压根没注意到他。

林川看了一会儿，又慌忙把视线收回来。图书馆这么安静，他怕自己的目光太明显。

看了两行，一个字没进脑子。

就在他第三次把同一页书看串行的时候，耳边忽然传来一个声音，很轻，很清晰：

"林川。"

他一激灵，抬头。

苏念不知道什么时候，已经坐到了他对面。她手里拿着几张纸，是他俩小组作业的资料。

"这个数据，"她指着其中一行，"你查的时候，来源是哪个网站？我这里对不上。"

林川愣了一下，随即反应过来，是小组作业的事。

他下意识地，又想去读她的心声，看看她到底卡在哪。可那一片，还是静悄悄的。

没有捷径。

他只好把资料接过来，仔细看。

这一看，他反倒静下来了。

苏念的问题很具体。哪个数据、哪一行、对不上哪里，她说得清清楚楚。他低头看那几页资料。苏念的字很工整，在每一处对不上的地方，都用铅笔圈了出来，旁边写了个小问号。她做事，比他想的还要细致。

林川就着她的问题，一条一条回想，把自己查资料时的来龙去脉，慢慢说给她听。

"这个数据，是我在官网上扒的，可能跟你找的那个版本不太一样。"他说。

"官网哪一栏？"她问。

"企业年报那块，往下拉，有个历史数据。"

苏念点点头，低头在本子上记了几笔。过了一会儿，她又问：“那这个呢？”

一来二去，两人对出了三处不一样的地方。有的错在官网改版，旧数据挪了位置；有的错在单位，一个用了万元，一个用了元。林川拿笔在纸上写写画画，苏念凑过来看，两人中间那几厘米的距离，谁都没留意。

两人就这么，一个问，一个答，头对着头，压低了声音，怕吵到别人。

说着说着，林川忽然发现，自己已经很久没这么认真跟人说过话了。

她就那么问，他就那么答，问什么答什么，没听懂就再解释一遍。他甚至连自己说话的声音，都比平时轻了三分。

中间有几次，林川说到一半卡住了。放在以前，他肯定要慌了，会急着用读心去猜对方想听什么。可这会儿，他发现自己居然不慌。卡住了就停一下，想一想，再慢慢说。

他头一回，没靠读心，把一场天聊了下来。

气氛意外地自然。

林川一边说，一边听她偶尔插进来的问题。她说话很慢，声音不大，可每一句都问在点子上。

他还偷偷观察她。她皱眉的时候，说明这地方她没听懂；她点头的时候，说明他答到了她想问的点上。这些细微的表情，他以前从来不注意，现在却看得一清二楚。

他头一回觉得，猜一个人的心思，原来也这么有意思。虽然猜错的多，猜对的少，可每猜对一次，都跟解了一道难题似的。

他心里忽然冒出个念头：要是能一直这么聊下去，该多好。

这个念头刚起来，他自己先红了耳根。

他忽然发现，原来光靠听，也能听出很多东西。

她做作业很较真，一个数据对不上，就非要追到源头。她说话不绕弯子，问什么就是什么。她听别人说话的时候，眼睛会认真地看着对方，偶尔轻轻点一下头。

这些，都是他以前靠读心，永远也听不到的东西。

他想起自己以前，总以为读心是了解一个人最快的路。现在才发现，有些东西，读心给不了，得靠时间，靠耐心，靠一句一句地听。

原来，一个人不用被看穿，也能被了解。

问题解决完，天也擦黑了。图书馆里的人陆陆续续往外走。

等最后一处也对上，林川才发现，窗外天都暗了。这一下午，过得比他想的快多了。

林川收拾东西，正准备起身，苏念也站了起来。她背好书包，看了他一眼，忽然轻轻说了句：
"明天见。"

说完，她转身走了。

林川站在原地，愣了两秒。

就这么三个字，普普通通。可他心里，却像被什么东西轻轻撞了一下。

他忽然觉得，这句“明天见”，比他这些天读到的任何一句心声，都让他高兴。

他站在那儿，看着苏念的背影拐出图书馆大门，才慢慢回过神。旁边有人经过，心里嘀咕着“这人站这儿傻笑什么”。林川一个激灵，赶紧低头，假装整理书包。

可嘴角压了又压，还是翘了上去。

他拎起书包，追着她的方向，走出图书馆。外面天黑了，路灯亮着，她的背影就在前面不远处，一步步，走得不紧不慢。

林川没有追上去。他就那么不紧不慢地跟在后面，保持着几步的距离。

今天这一下午，是他这些天来，过得最踏实的一下午。他嘴角，不自觉地翘了起来。
