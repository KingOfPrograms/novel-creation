# 关不掉，那就先忍着

第二天，林川决定跟这能力较劲。

说来也怪，早上睁眼那一下，他脑子出奇地清醒。耳边安安静静，静得他都有点不习惯。

他坐起来，愣了两秒，心里一喜：难道睡一觉就好了？

可这念头刚起，门外走廊里的声音就漏了进来，有人去洗漱，有人赶早课，有人在心里抱怨这破学校起得早。

得，还是那个德性。

他从高博桌上抽了张草稿纸，趴在床上，把自己能想到的办法一条条列出来。

第一条，戴耳机。昨天试过了，挡不住。画个叉。
第二条，转移注意力。心里默念别听别听，用别的事把脑子占满。没试过，画个问号。
第三条，躲着人走，哪人少待哪。食堂那一关已经证明躲不掉。画个叉。
第四条，早睡早起，养足精神。他怀疑自己是没睡好才头疼，先试试。
第五条，喝酒。听说喝晕了什么都不知道。想想还是算了，被逮住处分。
第六条，把自己累晕过去，累到没力气想事。
第七条，找个没人的厕所待着。
第八条。

写到第八条，他停了笔。他发现一个残酷的事实：他连这能力到底是个什么玩意儿都没搞清，就急着想关掉它，跟一个人不知道病在哪、就乱吃药一个道理。

写到最后，笔一丢，纸上横七竖八躺着十几条，活像个走投无路的人列的遗书。

"先试最靠谱的。"他坐起来，给自己打气。

第一条老早就废了。他直接跳到第二条，戴上耳机，把音乐开到最大，然后开始默念：别听，别听，别听。

一秒后，高博从门口晃进来。林川清清楚楚听见他心里那句：【这货又发什么神经，大白天戴个耳机念经。】

"没用。"林川把耳机摘了，叹了口气。

他决定换招，试试放空。他走到洗手台前，对着镜子，闭上眼睛，深呼吸，努力让自己脑子一片空白。

空白维持了大约三秒。

然后周航在楼下打游戏的声音就漏了进来，直接钻进他脑子：【这队友是人机吧。】

林川睁开眼，瞪着镜子里的自己。镜子里那人也瞪着他，眼圈发青，头发睡得乱糟糟，脸色白得像三天没睡。

"我跟你拼了。"他压低声音，像在对镜子里的自己宣战。

说拼就拼。他试了数数，从一数到一百，数到二十三就被楼下的心声打断。他试了念经，阿弥陀佛念了半句，隔壁床在心里吐槽的声音就插了进来。他试了掐自己，手背掐得青一块紫一块，该听的一个没少听。

他还真去卫生间躲了一会儿。宿舍楼里最安静的地方就是卫生间，可那地方也躲不开，楼上有人冲水，他心里就在想这水声真大。

可越是想控制，事情越糟。

下午，他躲进图书馆，找了个最角落的位置，以为安静的地方能让他静下来。结果图书馆是安静，安静得反而衬得每一个念头都格外清楚。自习的人表面都在翻书，心里各有各的兵荒马乱：有人为考研焦虑，有人偷偷想着隔壁座的女生，有人盘算晚饭吃什么。几百条念头，在安静的空气里，比食堂那会儿还响。

二楼靠窗的位置早被占了，他只能缩到书架背后的楼梯间。楼梯间阴凉，偶尔有人上楼下楼，脚步声在空旷里回响。他本以为这里清静，可每上来一个人，那人的念头就跟脚步一起，一步一声，砸在他脑袋上。

林川抱着头趴在桌上，连翻书页的力气都没了。

傍晚，他从图书馆出来，天已经擦黑。校园里三三两两的人，各自带着各自的心事从他身边走过。他忽然不想跑了，就那么慢慢走着，任由那些念头从他脑子里淌过去，像一条不会干的河。

也就在这么走着的时候，他隐约摸到了一点规律。

他回想着这一天，忽然发现：那些让他最难受、最想逃的时候，恰恰是他自己最紧张、最在意的时候。

中午食堂人最多，他怕当众出丑，越怕，声音就越铺天盖地。刚才在图书馆，他拼命想关掉，结果听得比谁都清楚。

反过来，凌晨那会儿他困得睁不开眼、什么都顾不上想的时候，那些声音反倒最模糊。

他又想起一个细节。昨晚睡前，他困到极致，意识都飘了，那时候满楼的心声跟远去的潮水似的，一句也抓不住。而白天在食堂，他脑子里那根弦绷得死紧，反而把几百个人的念头都放大了。

他慢慢坐直了身体。

**越紧张、越在意，就听得越清；越放松、越无所谓，声音反倒越远。**

这条规律一出来，他先是一喜，紧跟着又垮了脸。

因为这规律有个要命的地方，他现在满脑子都是"我要关掉它"，这本身就是一种在意。

于是死循环就来了：想关掉 → 紧张 → 听得更清 → 更想关掉 → 更紧张。

他像一只追自己尾巴的猫，越追越晕，越晕越追。

那天下午，他就这么跟自己较了一下午的劲。图书馆、卫生间、楼梯间，他换着地方躲，声音也跟着他换着地方响。到最后，他瘫在操场边的长椅上，仰头看天，看着看着，忽然就笑了。

他想明白了：跟它硬碰硬，自己永远是输的那个。

晚上十点，他筋疲力尽地回到宿舍，把那张写满办法的草稿纸揉成一团，用力扔进垃圾桶。

"关不掉。"他躺回床上，认命地盯着天花板，"那就先忍着。"

可他心里清楚，忍着不是办法。这玩意儿已经跟他的神经长在一起了，躲不掉，关不掉，只能学着跟它共处。

或者，先弄明白它到底是什么。

这个念头一冒出来，他自己先愣了一下。是啊，从昨晚礼堂那声嗡鸣开始，他一直只顾着怎么关掉，从来没认真想过一个问题。

这能力，到底是怎么来的？

为什么偏偏是他？

还有那晚那句不属于任何人的话，果然，来了，到底是什么意思？

林川翻了个身，把脸埋进枕头。这一夜，他脑子里除了满楼的心声，头一回多了一个属于自己的、安静的念头。

他想弄明白它。

这大概是他跟这能力，第一次真正意义上的和解。

他闭上眼，不再躲那些声音，任由它们从耳边流过。满楼的人还在想各自的心事，而他第一次，想听听这能力自己想说点什么。

窗外，操场的灯还亮着，几声篮球落地的闷响，一声接一声。他把这些都听进耳朵里，头一回不觉得吵。那些声音像潮水一样涌来，又慢慢退去，而他，还稳稳地躺在原地。

夜渐渐深了。
