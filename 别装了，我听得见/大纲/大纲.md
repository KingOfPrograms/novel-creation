# 大纲

## 全书体量与阶段总览

- 全书总章节数：约 600 章
- 目标字数：150 万字（每章约 2500 字）
- 全书情绪曲线：轻松期待 → 加压反转 → 爽感震撼 → 余韵圆满（轻松向打底，异能暗线逐步加压，终局揭真相收官）

### 阶段划分
1. 开篇期（第 1-100 章，约 25 万字，约 17%）：核心任务 = 立人设、立世界观、埋主线钩子、完成第一次异能危机闭环；情绪基调 = 轻松/期待/小刺激；阶段结束时读者应建立 = 对林川「读心看穿反差」爽点的认同 + 对「女主读不到」与「异能世界」的期待
2. 发展期（第 101-340 章，约 60 万字，约 40%）：核心任务 = 异能世界展开、组织登场、读心升级、支线并行、关系升温；情绪基调 = 期待/紧张/间歇爽感；阶段结束时读者应建立 = 对「异能组织」与「苏念秘密」的迫切期待
3. 高潮期（第 341-460 章，约 30 万字，约 20%）：核心任务 = 幕后主使对决、多线收束、情感确定；情绪基调 = 爽感/震撼/反转；阶段结束时核心矛盾应 = 头号宿敌被解决，苏念关系确定
4. 收尾期（第 461-600 章，约 35 万字，约 23%）：核心任务 = 终极真相揭晓、金手指上限解锁、身份落定、结局余韵；情绪基调 = 释然/感动/圆满；阶段结束时主线伏笔应 = 回收完毕（为何觉醒、苏念为何读不到、读心上限），结局落定

> 注：第五卷是「高潮 + 收尾」复合卷，故收尾期占比高于常规 5%-10% 参考值——它既要揭终极真相、又要解锁第 6 层、还要收干净身份/情感两条线。

### 各阶段节奏公式
- 开篇期：核心任务 = 觉醒 + 校园日常 + 女主群建立 + 伪装者闭环；情绪基调 = 轻松为主、伪装者段提压；爽点密度 = 每 2-3 章一个读心看穿的小爽点；伏笔策略 = 埋「异能非偶然」「苏念读不到」「异能世界」三颗长期种子；冲突层级 = 校园小恶 → 伪装者；阶段钩子 = 伪装者事件牵出异能世界；禁止提前释放 = 苏念读不到的原因、组织幕后主使、读心第 4 层以上
- 发展期：核心任务 = 异能圈子展开 + 组织干部/高层 + 读心升到第 4 层；情绪基调 = 期待/紧张交织、爽感间歇兑现；爽点密度 = 每单元 1 个大爽点 + 若干小爽点；伏笔策略 = 苏念秘密、觉醒真相逐步加压；冲突层级 = 组织干部 → 组织高层；阶段钩子 = 高层败退指向幕后主使；禁止提前释放 = 幕后主使真容、觉醒终极真相
- 高潮期：核心任务 = 幕后主使正面对决 + 读心第 5 层 + 苏念确定关系；情绪基调 = 爽感/震撼/反转；爽点密度 = 连续爽点；伏笔策略 = 大量回收、留终极真相到收尾期；冲突层级 = 幕后主使；阶段钩子 = 主使败亡后牵出「真相尚未揭晓」；禁止提前释放 = 觉醒终极真相、读心第 6 层
- 收尾期：核心任务 = 揭终极真相 + 解锁第 6 层因果预判 + 身份终局 + 关系圆满；情绪基调 = 释然/感动/圆满；爽点密度 = 真相揭晓 + 金手指上限的震撼；伏笔策略 = 全部回收；冲突层级 = 真相层面的最终抉择；阶段钩子 = 无（结局落定）；必须回收清单 = 为何觉醒、苏念为何读不到、读心上限、异能世界秩序、与苏念的关系、主角身份终点

### 关键节点与钩子链
- 关键转折点：第 50 章（伪装者初现、读心第一次失灵）、第 220 章（异能世界正式展开）、第 460 章（幕后主使对决落幕）、第 560 章（终极真相揭晓）
- 小/中/大高潮：小高潮第 92 章（第一卷伪装者对决）、第 220 章（第二卷组织干部）等；中高潮第 460 章（第四卷幕后主使）；大高潮第 560 章（第五卷终极真相）
- 阶段钩子链：开篇期结尾（伪装者事件牵出异能世界）→ 发展期；发展期结尾（高层败退指向幕后主使）→ 高潮期；高潮期结尾（主使败亡、真相未揭）→ 收尾期

## 卷级大纲

### 第一卷：觉醒（约 25 万字，100 章）
- 功能：铺垫 + 起步 + 第一个大爽点（读心看穿反差的校园喜剧 + 伪装者异能危机闭环）
- 所属阶段：开篇期
- 卷契约：轻松校园日常的信息差喜剧、看穿人心的掌控感、女主读不到的钩子、第一个异能危机
- 终局储备：读心升到第 3 层（表层心声 → 噪音过滤 → 深层心声）；异能者世界第一次显形；苏念「读不到」钩子立起但不解释
- 阶段边界：可释放 = 读心第 1-3 层、女主群建立、伪装者真身；禁提前释放 = 苏念读不到的原因、组织幕后主使、读心第 4 层以上、觉醒真相
- 核心事件：林川觉醒读心、在校园里靠「听」游刃有余，却栽在能伪装心声的对手身上，最终升级能力揭穿对方，牵出异能者世界
- 起始状态 → 结束状态：林川从「被动听、信息过载、只想关掉能力」的普通大学生，变成「初步掌控读心、察觉异世界存在」的觉醒者

### 第二卷：入局（约 30 万字，120 章）
- 功能：异能世界正式展开 + 读心升到第 3 层 + 组织干部登场
- 所属阶段：发展期（前半）
- 卷契约：异能者圈子与组织的初步面貌、读心更深层的爽感、苏念秘密加压、关系升温
- 终局储备：读心第 4 层（情绪底色）初探；异能组织第一次正式接触（态度未明）
- 核心事件：伪装者事件牵出异能者圈子，林川被组织盯上，与组织干部第一次交锋
- 起始状态 → 结束状态：林川从「刚触及异世界的散人」，变成「被组织正式注意、主动或被迫卷入异能者秩序」的关键人物

### 第三卷：对峙（约 30 万字，120 章）
- 功能：组织正面交锋 + 读心升到第 4 层（情绪底色）+ 组织高层登场
- 所属阶段：发展期（后半）
- 卷契约：与组织的对抗升级、读心对「说谎/伪装」的进一步克制、苏念秘密逼近、多隐线关系收束或转向
- 终局储备：读心第 4 层（情绪底色）巩固、第 5 层（记忆碎片）初现；组织高层显形；苏念「读不到」的线索开始显山露水
- 核心事件：林川与组织高层正面博弈，读心升到第 4 层，苏念的秘密被逼近但未揭穿
- 起始状态 → 结束状态：林川从「被组织拿捏的棋子」，变成「能与组织高层博弈、且握有关键信息」的对等玩家

### 第四卷：宿敌（约 30 万字，120 章）
- 功能：高潮 + 幕后主使对决 + 读心升到第 5 层（记忆碎片）+ 苏念关系确定
- 所属阶段：高潮期
- 卷契约：头号宿敌（组织幕后主使）的终极对决、情感线的确定、读心记忆碎片的高风险爽点
- 终局储备：读心第 5 层（记忆碎片）；幕后主使落败；与苏念确定关系
- 核心事件：林川以第 5 层读心与布局正面击败组织幕后主使，同时与苏念确定关系
- 起始状态 → 结束状态：林川从「博弈者」变成「终结宿敌、抱得情感归宿」的强者

### 第五卷：真相（约 35 万字，140 章）
- 功能：高潮 + 收尾（终极真相揭晓 + 读心第 6 层因果预判 + 身份终局 + 关系圆满）
- 所属阶段：收尾期（复合高潮）
- 卷契约：为何觉醒、苏念为何读不到、读心上限三大终极真相；第 6 层因果预判的震撼；身份地位终点；与苏念的圆满结局
- 终局储备：读心第 6 层（因果预判）；终极真相全部揭晓；主角在异能世界的关键位置落定
- 核心事件：林川揭晓觉醒与苏念「读不到」的终极真相，解锁因果预判，重建/稳固异能世界秩序，圆满收官
- 起始状态 → 结束状态：林川从「强者」变成「洞悉真相、站在异能世界关键位置的守护者」
