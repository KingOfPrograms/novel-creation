## 细纲（第 3 章）

### 第 3 章：你说得对，但我信你心里那句

- 核心事件：第一个爽点——识破室友高博的口是心非，小打脸 + 化解尴尬
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01 第 3 拍（尝试：第一个读心爽点）
- 目标情绪：疲惫烦躁 → 解气小爽（第一次主动用能力翻盘）
- 主角目标/关键选择：第一次主动「用」读心；在揭穿与给台阶之间做选择，选择「看破也说破一点」、点到为止
- 章首钩子：反差场景 — 高博当众吹牛「我跟学生会主席铁得不行」，林川耳边却听见他心里嘀咕「完了，这牛吹大了」
- 爽点：识破口是心非、小打脸（第一个读心爽点，兑现黄金三章的期待）
- 本章禁止提前释放：不出场苏念；不让林川暴露能力（他只能用「猜」圆过去）；不出现第二个觉醒者

#### 内容概括

- 起因：高博当众吹牛，眼看要圆不回来
- 发展：林川「听见」高博心里的慌，开始犹豫要不要帮
- 转折：林川第一次主动用读心，精准接话帮高博圆场，也顺便拆了他一点台
- 高潮：高博被拆穿又获救后的错愕，周围人觉得林川「神了」
- 结尾：高博追问「你怎么知道的」，林川含糊带过

#### 情节安排

- 主线推进：L01 从「失控」推到「第一次主动使用」
- 辅线推进：L03 高博与林川关系从「室友」推到「被看穿后服气」
- 事件线 / 任务线：高博的吹牛现场这个日常小事件
- 感情线 / 关系线：无显性，但高博对林川的态度本章起变化
- 逻辑线：高博吹牛过头 → 林川听见他心虚 → 主动接话圆场拆台 → 高博错愕 → 追问被糊弄过去

#### 人物关系和出场顺序

- 出场顺序：高博 → 林川 → 围观同学（群像，可略）

- 视角/信息差：林川知道高博的慌是装的，高博不知道；围观同学不知道林川有读心，只觉得他「会说话」
