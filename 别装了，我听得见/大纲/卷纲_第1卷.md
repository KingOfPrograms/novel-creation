# 觉醒 卷纲

> 作用域：卷级常任

## 核心信息

> 作用域：卷级常任

- 章节范围：第 1-100 章
- 字数目标：25 万字（每章约 2500 字）
- 本卷定位：开篇期（铺垫 + 起步 + 第一个大爽点闭环）

## 卷契约与终局储备

> 作用域：卷级常任

> 单章放开密度、宏观管住终局储备。主推线之外的线按剧情自然给战果，一战多得允许；真正要守的是本卷别动用还不该解锁的终局底牌。

- 卷契约：轻松校园日常的信息差喜剧 + 看穿人心的掌控感 + 女主「读不到」的钩子 + 第一个异能危机（伪装者）
- 本卷主推线：读心能力成长线（第 1 层表层心声 → 第 2 层噪音过滤 → 第 3 层深层心声）
- 本卷战果：关系线（苏念 / 温以宁 / 唐果 / 沈清逐一建立并出反差）、校园生活线（读心带来的小逆袭与打脸）、异能世界暗线（第一次显形）
- 本卷解锁的终局里程碑：读心第 3 层（深层心声，卷末应对伪装者时突破）；异能者世界第一次显形
- 本卷禁碰的终局底牌：苏念「读不到」的原因、异能组织幕后主使、读心第 4 层以上、林川觉醒的真相
- 本卷鼓励长出的：校园日常的读心爽点场景（课堂/宿舍/社团/打工）、伪装者的具体能力与动机、各隐线女主的标志反差事件、异能者圈子的初见规则
- 契约风险：契约安全（爽点、钩子、代理权、利益安全线均有交代；苏念读不到与异能暗线作为长期期待债已埋，不提前拆）

## 本卷故事线（L 编号唯一分配处；主线之外至少 2 条）

> 作用域：卷级常任

> 比剧情单元大一层的横向线。剧情单元卡「本单元在跑的线」按 L 编号引用本表。支线必须与主线有对接口。

| 编号 | 线 | 类型 | 推进靠什么 | 与主线怎么对接 | 本卷区间 | 主线停摆时能否单独扛一章 |
|---|---|---|---|---|---|---|
| L01 | 读心觉醒与掌控 | 主线 | 觉醒失控 + 信息过载，逼林川学「过滤」；伪装者出现后逼他练「深层心声」 | 能力升级直接用于揭穿伪装者（卷末对决） | 第 1-100 章 | 能（能力失控、修炼本身就是戏） |
| L02 | 林川 × 苏念 | 关系（正主） | 「读不到」的强烈好奇 + 被迫用真实相处去了解她 | 苏念的秘密与异能世界暗线同源（第二卷起显） | 第 6-100 章 | 能（与苏念的相处日常可单独成章） |

| L04 | 伪装者 | 对手线 | 伪装者在校园里暗中用「伪装心声」操控他人、牟利 | 卷末正面对决，是主线 L01 的逼升级引擎 | 第 37-92 章 | 只能半章（需主线推动） |
| L05 | 异能者世界初见 | 信息/暗线 | 伪装者事件牵出「觉醒者不止林川一个」 | 卷末钩子把第二卷「入局」接上 | 第 50-100 章 | 不能（只是钩子，第二卷才展开） |

## 剧情单元卡（1–3 万字为可调经验值；存于卷纲内；不另建单独文件）

> 作用域：卷级常任

> 剧情单元卡与「对标结构坐标」是同一单元的不同视角，不重复编排。单元长度按本书题材、兑现节奏与对标调整，不是硬门槛。规划各关键节点按「契约四问」检查；高潮/兑现后可留短暂低压，以小而可见的收益承接下一轮压力。

### 剧情单元 L1-01

> 作用域：单元级 L1-01

- 单元ID：L1-01
- 章节范围：第 1-10 章
- 对标剧情参照：自创：开篇黄金三章 + 觉醒喜剧（对标书《很纯很暧昧》金手指梯度升级思路，但拆文库无该拆文，节奏按八节点自排）
- 单元节拍/章功能分配：建立期待（第 1-2 章觉醒与失控）→ 尝试（第 3 章第一个读心爽点）→ 加压（第 4-5 章信息过载代价 + 想掌控）→ 决定性行动（第 6-8 章主动用读心完成第一次小逆袭）→ 兑现（第 8 章爽点闭环）→ 余波（第 9-10 章埋「异能非偶然」种子、引下一单元）
- 单元承诺：读者立刻看懂「读心看穿反差」的爽点，并产生「他之后会怎么用这个能力」的期待
- 单元情绪引擎：核心情绪命题 = 信息差喜剧 → 承载对象 = 身边人的口是心非（室友/同学/学长）→ 受阻或缺口维持原因 = 初期被动听、无法过滤、信息过载 → 本轮触发 = 林川第一次主动利用读心化解尴尬/识破谎言 → 主角不可替代的点火/转化动作 = 林川在社死瞬间选择「听见」并顺势反杀 → 意义变化或可见兑现 = 从「被吐槽的透明人」变成「看穿全场的人」 → 题材/契约兑现 = 轻松喜剧 + 掌控感
- 卷级贡献：立住主角、金手指、基调三件事，兑现黄金三章
- 主角局部目标与核心利益：摆脱被动挨听的混乱，第一次尝到「看穿」的甜头
- 因果入口：新生晚会社死瞬间（情绪爆点触发觉醒）
- 核心阻碍：读心被动触发、无法过滤、信息过载到头疼
- 关键选择与决定性行动：林川在满场心声里，选择不听自己的窘迫、而是利用别人的口是心非化解尴尬（第一次主动使用能力）
- 兑现方式与归属：识破某人口是心非当众打脸，收益归林川（获得「看穿」的掌控感与第一次小胜利）
- 本单元主推线/战果：主推线 L01（能力觉醒）；战果 L03（第一个爽点牵出某隐线女主的初见）
- 本单元在跑的线：L01 从「觉醒失控」推到「初尝甜头」；L03 从「无」推到「某女主初见」
- 终局底牌边界：不动用第 2 层以上能力；不解释觉醒原因
- 禁止提前释放：不出现「异能非偶然」的直接答案、不出现异能组织、不出现苏念读不到的解释
- 下一单元因果钩子：信息过载逼林川想「掌控能力」，同时苏念（读不到的人）进入视野
- 契约风险：契约安全

### 剧情单元 L1-02

> 作用域：单元级 L1-02

- 单元ID：L1-02
- 章节范围：第 11-22 章
- 对标剧情参照：自创：女主「读不到」钩子 + 被迫真实相处（情感线起点，克制暧昧，不照搬后宫流）
- 单元节拍/章功能分配：建立期待（第 11-12 章林川主动接近、发现读心套路对苏念全废）→ 尝试（第 13-16 章林川用读心者的惯性试探、旁敲侧击，全部碰壁）→ 加压（第 17-19 章被苏念的「无信息差」逼到不会相处，过度自信弱点暴露）→ 决定性行动（第 20-21 章林川第一次彻底放弃读心、靠真实相处了解她）→ 兑现（第 21 章暧昧起点）→ 余波（第 22 章苏念身上似有秘密）
- 单元承诺：展开全书情感线核心张力——「读心者的傲慢 vs 读不到的人」（钩子已于第 6 章抛出）；读者期待他什么时候能读懂她、她到底为什么读不到
- 单元情绪引擎：核心情绪命题 = 好奇心 + 暧昧 → 承载对象 = 苏念（唯一读不到的人）→ 受阻或缺口维持原因 = 读心对苏念完全无效（原因不许揭）→ 本轮触发 = 林川越想读越读不到 → 主角不可替代的点火/转化动作 = 林川放弃「读」，改用「观察+相处」去了解她 → 意义变化或可见兑现 = 感情在信息缺失中萌芽，比读心得来的更真实 → 题材/契约兑现 = 克制暧昧 + 女主钩子
- 卷级贡献：立起情感线正主，兑现「女主读不到」这一核心资产
- 主角局部目标与核心利益：弄懂「为什么读不到她」，不自觉开始在意她
- 因果入口：L1-01 的钩子（苏念进入视野）
- 核心阻碍：读心失效 + 林川「只听表层心声就过度自信」的弱点第一次暴露
- 关键选择与决定性行动：林川选择不靠能力作弊，而是用笨办法靠近苏念
- 兑现方式与归属：苏念对林川的「特别」产生一丝不同（暧昧起点），收益归林川（情感线推进）
- 本单元主推线/战果：主推线 L02（情感线起点）；战果 L01（读心弱点被正视，为后面升级埋因）
- 本单元在跑的线：L02 从「无」推到「暧昧起点」；L01 从「初尝甜头」推到「意识到能力有盲区」
- 终局底牌边界：不解释苏念读不到的原因；不出现苏念的异能相关线索（留到后面卷）
- 禁止提前释放：苏念读不到的答案、苏念与异能世界的关联
- 下一单元因果钩子：林川开始系统用读心在校园里「搞事情」，同时隐线女主群陆续登场
- 契约风险：契约安全

- 对标剧情参照：自创：校园日常多场景读心爽点（对标《很纯很暧昧》「异能落地日常」思路）

- 关键选择与决定性行动：林川在「帮不帮」的关口多次选择出手（用读心帮被坑的人、揭穿算计）
- 兑现方式与归属：多个小打脸 + 一次较大误会化解，收益归林川（声望 + 三条隐线女主的认可）
- 本单元主推线/战果：主推线 L03（三条隐线建立）；战果 L01（能力熟练度提升、副作用显形）
- 本单元在跑的线：L03 从「初见」推到「三条隐线各自建立」；L01 从「有盲区」推到「副作用逼出升级需求」
- 终局底牌边界：读心仍是第 1 层，不得读到「深层心声/真实意图」级别（那是第 3 层）
- 禁止提前释放：不出现能伪装心声的对手（伪装者下一单元才登场）
- 下一单元因果钩子：副作用到极限 + 校园里第一次出现「读出来是假」的异常心声
- 契约风险：契约安全

### 剧情单元 L1-05

- 对标剧情参照：自创：升级突破（对应《很纯很暧昧》「金手指梯度升级」的爽点循环）

## 全卷常任裁定

> 作用域：卷级常任

{对本卷每个剧情单元生效的规则本文写在这里，单元卡只写落点、不复读规则}

1. **读心层级封顶**：本卷林川的读心只到第 3 层（表层心声 → 噪音过滤 → 深层心声）。任何单元不得出现第 4 层「情绪底色」及以上的能力（读情绪波动、读记忆、读因果）。
2. **苏念读不到且不解释**：苏念的心声对林川完全无效，本卷任何位置不得给出原因或暗示其与异能世界的关系（终极真相留第 5 卷）。
3. **能力不暴露给公众与无关机构**：读心能力只在小范围可信关系里被知晓（最多被苏念与极少数亲近之人察觉），不得上热搜、不得被学校官方或外部机构掌握（利益安全线）。
4. **轻松基调底线**：异能危机可以紧张、可以栽跟头，但不写沉重、血腥、死亡阴影、家庭惨剧；伪装者作恶控制在「操控人缘/利益/感情」层面，不升级为伤人性命（读者契约 = 轻松向）。
5. **林川的弱点必须持续有效**：凡林川仅凭「表层心声」下判断的场合，允许并鼓励他出错；只有当判断基于「观察+证据+深层心声」时才可作准。这一条贯穿全卷，防止读心写成万能偷窥。
