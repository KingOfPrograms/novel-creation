# 女主卡：苏念

- 姓名：苏念
- 性别：女
- 角色功能：正主女主 / 读心失效的唯一对象 / 长线钩子载体
- 与主角关系：同班同学 → 暧昧 → 恋人（第4卷确定关系）
- 核心特质：安静低调、存在感低、内心有主见
- 标志性特征：主角唯一读不到心声的人；总在角落安静看书，偶尔抬头时眼神很静，像有另一个世界
- 退场方式：全书女主，不退出（「为什么读不到她」的真相在第5卷揭晓）

## 补充设定

- 人设反差：表面是班里最不起眼的普通女生，实际藏着与异能世界有关的秘密（暗线，不提前拆穿）。
- 功能设计：她是读心金手指的「唯一盲区」——正因为读不到，主角才第一次被迫用真实相处去了解一个人，感情因此成立而非"作弊读心"。这是全书情感线最核心的设定。
- 暧昧节奏：克制、慢炖，靠"读不到"制造的误会与好奇推进，不靠读心偷看心意。
