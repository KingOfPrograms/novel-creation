# 三师（三位师父）

> 三段师承=全书成长节奏器（引擎支柱②）；三人都是主角身边的市井小人物（"高手在民间"），都住在面馆半径 500 米内，最后都死/离场，把"力量+情感"留给陈默。

## 老宋（师傅①）
- 身份：收废品的瘸腿老头；实为听风会叛出的"静耳人"
- 功能：导师 / 第一次黑化的触发者
- 教什么：**"静耳"**——关闭能力，学会"不听"（自保与克制）
- 标志：永远拖着一辆吱呀响的板车；只在夜里敲面馆后门
- 退场：为护陈默被两派灭口 → 陈默第一次黑化（用"寂"让一条街死寂）

## 老关（师傅②）
- 身份：夜班黑车司机；实为寂声局叛出的"封口人"
- 功能：导师 / 立场摇摆者
- 教什么：**"借声"**——把听见的"重音"化为己用（共振）
- 标志：车里永远放一首卡带的旧歌；话比陈默还少
- 退场：身世揭示后与陈默立场对立，最终为挡一次致命的"静默"而离场

## 老穆（师傅③）
- 身份：面馆楼上的盲人调音师；实为两派共同的祖师级人物
- 功能：导师 / 灌顶者 / 身世揭示者
- 教什么：**"合一"**——把"声"与"寂"在陈默身上第一次合流，能力质变
- 标志：一台老钢琴，只调不弹；听脚步就能认出整条街的人
- 退场：传功后离场（不写死，留余韵），把"调音人"的钥匙交给陈默
