# 平台适配 · 起点中文网

> 用途：把《静默区》从「番茄向」改写口径调到「起点向」。本文档给出差异依据、现状 gap、改造清单与已执行项。
> 结论口径：**起点吃"稳、代入感、世界观、升级路线、人设潜力"，番茄吃"快、强情绪、直给爽点"。本书原按番茄默认口径写，转起点需在"体系感 / 期待感 / 爽点落点"上补，节奏反而不必再提速。**

---

## 一、为什么改：起点 vs 番茄（依据）

| 维度 | 番茄（原口径） | 起点（目标口径） | 本书影响 |
|------|---------------|-----------------|---------|
| 核心取舍 | 节奏 > 代入感 | **代入感 > 节奏** | 本书第一人称+市井群像，代入感本就是强项，不用改 |
| 首章字数 | 1500–2000 | **2000–3000** | 现稿 2800 字/章，直接达标 |
| 开篇容忍 | 前 300 字 | **前 1000 字（可慢热）** | 可保留现有慢热开场，但钩子要更早兑现 |
| 冲突出现 | 前一章 | **第三章前** | 达标（老魏案第 3 章浮出） |
| 金手指亮相 | 前三章 | **前三章** | 达标（第 1 章第 2 句即点） |
| 爽点密度 | 每 2000 字 1 个 | **每 3000–5000 字 1 个** | **偏松，但"爽点"性质要换**（见 §二） |
| 编辑审核重点 | 完读/留存 | **世界观 / 升级路线 / 人设潜力** | **最大 gap**：前 3 章没有"声/寂体系"与"升级"暗示 |
| 开头策略 | 强情绪+强噱头 | 人物铺垫+慢热可接受 | 可留慢热，但主角要有"反击苗头" |
| 期待感 | 核心情绪反复提及 | **多线铺垫+伏笔** | 本书伏笔 F001–006 正好吃这口 |

**起点硬指标（2026 口径）**：签约线约 6000 字；开篇 300 字留存是算法核心；设定交代 ≤ 全文 15%；黄金三章分工固定为——
- 第 1 章：主角出场 + 核心钩子
- 第 2 章：**落地金手指 + 升级冲突**
- 第 3 章：**小闭环爽点 + 长线主线锚定**

## 三、改造清单

### 3.1 书名（A/B/C，待作者定）
| 方案 | 书名 | 类型 | 说明 |
|------|------|------|------|
| A | **《静默区》** | 逼格型（悬疑向） | 保留。起点吃"逼格起名法"，三字偏文艺；靠简介+开篇带。适合做"都市异能精品向" |
| B | **《我能听见你心里那句话》** | 金手指直给型 | 与第 1 章章名同源，3 秒传递卖点；略偏番茄风，但在起点"脑洞向"可跑 |
| C | **《全城失语》** | 主线悬念型 | 主线+危机感直给，四字有冲击；与"静默区"母题同源 |

> 起点规则：书名暗示的卖点 = 简介承诺 = 正文交付，三者必须一致。三案分别对应"悬疑/金手指/主线"三种导流入口。
> 推荐：**A 为主，C 为备**（本书内核偏悬疑精品，A 最贴；若首秀数据冷，切 C 换导流）。

### 3.2 简介（起点版 · 四段式成功型）
> 结构 = 情境 → 冲突 → 行动 → 成功暗示。给"安全感"，同时留钩子。

```
我能听见别人心里没说出口的那句话。

面馆少东家，外卖骑手，二十四岁。这副耳朵没给我带来一点好处——
听得见人心，却一个字都不敢说出口。

直到这条老街开始出事。熟人一个一个"哑"了：不是病，是有人在一寸一寸，
把他们的声音收走。收声音的人，顺着我的耳朵找来了。

退无可退，我只能做一件事：把听见的，一条一条查下去。

这一次，我不装了。
```

**字数**：约 180 字，起点简介区间内。
**安全感**：末句"这一次，我不装了"= 主角主动出击，暗示会赢。
**钩子**：老街失语 + 冲我来 + 我不装了，三连钩。

### 3.3 标签 / 分类（起点）
- 大分类：**都市**
- 子分类：**都市异能**（备选：异术超能）
- 标签：`都市异能` `悬疑` `推理` `群像` `市井` `脑洞` `轻松` `单女主`
- 说明：起点编辑建议"让智能推识别到固定受众"，故保留 `都市异能/悬疑/群像` 三个高辨识标签打头。

### 3.4 黄金三章（已按起点口径打磨，见 §四）
- 第 1 章：补"与读者的秘密互动"（都市文"私密"要素），钩子前置；
- 第 2 章：补一次**金手指小运用**（医院里的"小试牛刀"），并埋**体系感种子**（这不是普通听力，是有来路的东西）；
- 第 3 章：补**小闭环**（听见 → 做成一件事 → 拿到一次真实的情感/信息回报），给"反击苗头"。

### 3.5 节奏与爽点密度
- 起点可慢不能散。本书前 30 章以"查案推进 + 群像温情"双线，**每 3–5 章须有一个"信息释放点"**（查案有进展、信息差反超、打脸/解气）。已核对现有 30 章的信息释放节奏，标注缺口见 §五。
- 起点"爽点"本书形态 = **信息差反超 / 能力进阶 / 憋屈后的一次小释放**，不是"打脸升级"。避免为了密度硬塞装逼桥段。

### 3.6 文风与字数
- 文风：第一人称 + 市井温情 + 冷幽默，直接保留（起点比番茄更吃"文笔+人物"）。
- 字数：正文各章约 2800 字，落在起点 2000–3000 舒适区，**不再上调**。
- **例外**：黄金三章因补入起点要素（小运用/体系种子/反击苗头），略长至 2900–3200 字（ch1 2910 / ch2 3202 / ch3 3001），仍属起点常规区间，无需回削。
- 段落/标点：沿用现稿（短段、对话独立成行），起点无障碍。

### 3.7 更新与签约（运营项，供参考）
- 直发避周末/节假日，**周一早晨更新**最佳；内投不并行多投。
- 6000 字定生死：前 3 章即约 8400 字，已越过签约观察线，需保证前三章质量。
