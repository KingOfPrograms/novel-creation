## 细纲（第 3 章）

### 第 3 章：他心里有本还不清的账
- 核心事件：陈默借送单为由又去永安里，撞见来要账的老魏（建国修车铺的老板）；他听见老魏和夹克男人各自心里的重音，第一次能分清"哪句话来自谁"；回程路上，他第一次遇见收废品的老宋。
- 字数目标：2800 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01 第 3 拍（尝试·起）——第一句重音正式落到具体的人身上
- 目标情绪：从"没睡好、心里发毛，想弄清昨晚那句'本子'是啥"，到"看清两个男人的处境后，胸口发闷的'这事不对'"；推进引擎"触发＝第一句重音"。
- 主角目标/关键选择：目标＝弄清楚昨晚那句话属于谁、他在愁什么；关键选择＝他没报警（没证据、说了也没人信），而是记住老魏的铺子和长相，决定"改天再来看看"。
- 章首钩子：闪前碎片开局 — 一句"后来他才知道，如果那天他什么都没做，那个人也许不会死"，再切回上午的送单日常。
- 爽点：无显性爽点，功能是能力"方向感"坐实＋引出老魏这条线；章尾留钩。
- 本章禁止提前释放：不解释能力来源；不出现两派；不说破老魏与潘德是"欠债还账"的全部细节；不让老宋暴露任何身份。

#### 内容概括（五段式）
- 起因：陈默心里搁着昨晚那句"本子"，一早又看到永安里 202 的单，鬼使神差接了。到了没见着 202 的人，却发现隔壁墙上贴着"建国修车铺"的旧电话。
- 发展：他循着地址骑车到永和街东头的修车铺，借口给电动车打气；碰上穿皮夹克的男人（潘德）来还钱、耍赖，老魏（魏建国）跟他低声争了几句。陈默分别听见两人的重音——老魏："再拿不回来，这笔钱就砸在我儿子学费上了"；潘德："他要是敢把本子拿出去，就一了百了。"
- 转折：陈默这才分清"哪句是谁的"——他能"对上人"了。他没敢多待，非要塞两块钱气钱（其实打气不要钱），被老魏摆手拒绝。他第一次感到，自己听见的，都是别人最不想被人知道的。
- 高潮：临走时老魏忽然问他："小伙子，你说，一个人要是被人拿住了短处，是不是就只能认？"陈默答不上来。老魏笑了笑，说"没事，跟你瞎聊"。那笑比哭还难看。
- 结尾：回面馆的路上，陈默遇见拖着吱呀作响板车的收废品老头老宋，顺手把两包快过期的挂面递过去。老宋摆手"不赊"，陈默说"不要钱"，老宋就收了。走远时，陈默忽然发觉——这老头，是自己这条街上唯一一个"不吵"的人。

#### 情节安排（多线）
- 主线推进：L01 从"闻声"到能"对上人、分方向"（逼近应声的门槛）。
- 辅线推进：L03 从初现到成形——老魏的"本子"第一次当实物出现（明线是讨账，暗写"有人在替人处理见不得光的事"）。
- 事件线 / 任务线：去永安里 → 循地址到修车铺 → 打气 → 撞见潘德 → 听清两人重音 → 老魏问他话。
- 感情线 / 关系线：无显性，但关系变化为"陈默×老魏 从陌生到'他记住了这个人'；陈默×老宋 首次照面"。
- 逻辑线：想弄清"本子"（原因）→ 循线索找到修车铺（行动）→ 听清两人各自的着急与狠劲（结果）→ 他记住了老魏，也第一次意识到"听见"是种负担（后果）。

#### 人物关系和出场顺序
- 出场顺序：陈默 → 潘德（夹克男）→ 老魏 → 老宋。
- 人物关系变化：陈默×老魏（前）陌生（后）"陈默默默记挂的一个人"；陈默×老宋（前）无（后）照面、老宋是这条街上唯一"安静"的人。
- 视角/信息差：陈默知道老魏被"本子"逼着；读者由此确认昨晚的男人就是老魏；两人都不知道对方是凶手/受害者的位置。陈默误判"也许就是普通债务纠纷，不关我事"。
