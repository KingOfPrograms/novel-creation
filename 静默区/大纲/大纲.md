# 大纲

## 全书体量与阶段总览

- 全书总章节数：约 700 章（每章约 2800–3000 字）
- 目标字数：约 200 万字
- 全书情绪曲线：压抑/期待（卷1）→ 加压/黑化/反转（卷2-4）→ 震撼/燃（卷5-6）→ 释然/圆满（卷7）

### 阶段划分
1. **开篇期**（第 1-100 章，约 14%）：核心任务=立人设（陈默的善与无力）、立世界（声音暗战）、埋主线钩子（城市在变安静）；情绪基调=压抑+期待；阶段结束时读者应建立=对陈默的强认同 + 对"城市为什么在变安静"的强期待。
2. **发展期**（第 101-400 章，约 43%）：核心任务=矛盾展开（两派浮出、身世半揭）、支线并行（苏晚/小满/三师）、能力与关系升级；情绪基调=期待+紧张+间歇爽感；阶段结束时读者应建立=对最终反派（父亲/寂声局）的迫切期待。
3. **高潮期**（第 401-600 章，约 29%）：核心任务=小满之死→第二次黑化→真相全揭→两派总部对决；情绪基调=震撼+燃+痛；阶段结束时核心矛盾进入最终对决（父子）。
4. **收尾期**（第 601-700 章，约 14%）：核心任务=主声场决战、父子和解、伏笔回收、关系落定；情绪基调=释然+感动+圆满；阶段结束时主线伏笔回收完毕。

> 比例已按"情绪向都市异能 + 父子/黑化主干"上调高潮与收尾占比（发展期低于参考基线），不是机械套模板。

### 各阶段节奏公式
- 开篇期：核心任务=立人设/立世界/埋钩子；情绪基调=压抑+期待；爽点密度=每 3-5 章一小爽；伏笔策略=埋密码句、母亲之谜、面馆"静默怪事"；冲突层级=街头级；阶段钩子=卷末父亲线索；禁止提前释放=身世真相、声寂合一。
- 发展期：核心任务=两派浮出/身世半揭/关系升级；情绪基调=期待+紧张；爽点密度=每 3 章一冲突、每 7 章一大爽；伏笔策略=两派线索交织、母亲旧物；冲突层级=组织级；阶段钩子=指向高潮期的"大静默"前兆；禁止提前释放=父亲真身、金手指上限。
- 高潮期：核心任务=至亲之死/第二次黑化/真相全揭/两派对决；情绪基调=震撼+燃+痛；爽点密度=高压章密集（番茄档可到 30%+）；伏笔策略=集中回收中期伏笔；冲突层级=城市级；阶段钩子=父子终局；禁止提前释放=大静默的解法。
- 收尾期：核心任务=主声场决战/和解/回收/落定；情绪基调=释然+圆满；爽点密度=先燃后暖；伏笔策略=全部回收；冲突层级=本源级；阶段钩子=余韵；必须回收清单=密码句、母亲之死、父亲未说的重音、小满的写字板、老宋的板车。

### 关键节点与钩子链
- 关键转折点：第 62 章（老宋之死→第一次黑化，全卷最强）；第 470 章（小满之死→第二次黑化）；第 630 章（父亲真身与母仇真相全揭）。
- 小/中/大高潮：小高潮第 34/100/205 章；中高潮第 300/470 章；大高潮第 690 章（主声场·父子）。
- 阶段钩子链：开篇期结尾（第100章"父亲的影子"）→ 发展期；发展期结尾（第400章"大静默前兆"）→ 高潮期；高潮期结尾（第600章"父子对决将至"）→ 收尾期。

## 卷级大纲

### 第一卷：听见（约 28 万字，第 1-100 章）
- 功能：铺垫/起步/第一个大爽点（第一次黑化）
- 所属阶段：开篇期
- 卷契约：读者要看"一个能听见人心的老实人，如何在被利用与被伤害中第一次觉醒"；主角高光=第一次黑化（用"寂"让一条街死寂）+ 第一次反击；主要期待债=老宋之死的复仇债 + "城市为什么在变安静"
- 终局储备：主推线=战力线（闻声→应声→借声）；解锁里程碑=身世只揭"母亲不简单"一层；禁碰=父亲身份、寂声局高层、金手指上限、声寂合一
- 阶段边界：可释放=听觉能力规则、两派存在、苏晚/小满关系；禁提前释放=身世真相、声寂合流
- 核心事件：陈默因"听见人心"被卷入两派暗战，老宋为护他而死，他用"寂"让一条街死寂，卷末决定主动追查。
- 起始状态 → 结束状态：只想守好面馆的老实人 → 决定追查身世、主动入局的觉醒者
- 展开见 `大纲/卷纲_第1卷.md`

### 第二卷：静耳（约 28 万字，第 101-200 章）
- 功能：黑化后重建/发展
- 所属阶段：发展期
- 卷契约：读者要看"从塌方里爬回来的陈默，怎么把'善良'重新练成一种力量"；高光=第一次正面以"借声"击败清道夫；期待债=母亲之死的线索
- 终局储备：主推线=战力线（借声）；解锁里程碑=身世揭一半（母亲是听风会的人）；禁碰=父亲真身
- 核心事件：老关登场教"借声"，陈默在旧城区追查"封口网"，第一次真正对抗寂声局。
- 起始 → 结束：被保护的老实人 → 能主动用能力破局的猎手

### 第三卷：回声馆（约 28 万字，第 201-300 章）
- 功能：世界观扩张/组织级冲突
- 所属阶段：发展期
- 卷契约：高光=揭破听风会"重音黑市"；期待债=两派为何都想收编他
- 终局储备：主推线=信息线（两派结构）；解锁里程碑=身世半揭完成；禁碰=金手指上限
- 核心事件：陈默为救被卖"重音"的人闯入听风会回声馆，发现两派都在找他。
- 起始 → 结束：游离者 → 两派都想争取的关键人物

### 第四卷：封口（约 28 万字，第 301-400 章）
- 功能：加压/反向逼到极限
- 所属阶段：发展期
- 卷契约：高光=用"扬声"保住一圈人；期待债=大静默前兆
- 终局储备：主推线=战力线（扬声→静声边缘）；解锁里程碑=寂声局高层浮出；禁碰=父亲真身、声寂合一
- 核心事件：寂声局对整片老城发动"封口"，陈默第一次为护人而动用"寂"的力量，尝到代价。
- 起始 → 结束：猎手 → 被两派共同逼到绝境的守护者

### 第五卷：静声（约 28 万字，第 401-500 章）
- 功能：高潮期前段·至亲之死与第二次黑化
- 所属阶段：高潮期
- 卷契约：高光=第二次黑化（差点把整座城静音）；期待债=父子对决
- 终局储备：主推线=情感确定性（与苏晚）与身份线（父亲现身）；解锁里程碑=头号宿敌（父亲）正面现身；禁碰=声寂合一
- 核心事件：父亲陈邈现身，小满死，陈默第二次黑化失控，苏晚把他拉回。
- 起始 → 结束：守护者 → 直面父子渊源的矛盾体

### 第六卷：回响（约 28 万字，第 501-600 章）
- 功能：高潮期后段·真相与两派对决
- 所属阶段：高潮期
- 卷契约：高光=老穆灌顶、能力"回响"、真相全揭；期待债=大静默的解法
- 终局储备：主推线=战力线（回响）；解锁里程碑=真相/身世全揭；禁碰=金手指上限（无声）
- 核心事件：两派总部对决，母亲之死真相全揭，"大静默"发动。
- 起始 → 结束：矛盾体 → 知道自己是谁、要做什么的人

### 第七卷：无声（约 28 万字，第 601-700 章）
- 功能：高潮+收尾
- 所属阶段：收尾期
- 卷契约：高光=主声场决战、父子和解；期待债全部偿还
- 终局储备：主推线=战力线（无声·合流）与情感落定；解锁里程碑=金手指上限+身份终点（调音人）+情感确定
- 核心事件：陈默合流"声寂"，在主声场阻止大静默，听见父亲未说出口的重音，父子和解，城市复声，面馆重开。
- 起始 → 结束：矛盾体 → 两派共尊的调音人（暖收）
