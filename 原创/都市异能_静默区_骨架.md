# 原创骨架 · 都市异能《静默区》

> 用《善良的死神》的 6 根支柱引擎（见 `参考/善良的死神_结构拆解.md`）从零搭的**原创**故事。皮全是新的，只借结构关系。
> 面向：短篇 / 漫剧改编友好（场景少、人物少、强反转）。

---

## 一、一句话故事

**一个只能靠外卖谋生的城中村少年，能听见每个人心里最不肯说出口的一句话——唯独听不见自己的。当城市里所有声音开始被"收走"，他才知道：他那份"太善良"，是两股天生对立的力量，没在他身上分开。**

**标题候选**：《静默区》｜《听不见的人》｜《最后一个声音》

---

## 二、支柱逐条落地（这就是"用引擎搭出来的"证据）

| 引擎支柱 | 《静默区》里的落地 |
|---|---|
| ①极低起点+高贵底色 | 主角 **陈默**，26 岁，旧城区"永和面馆"少东家兼外卖骑手。外号 **"闷罐"**（外号即人设）。面馆常年给流浪汉赊账，他从不催。 |
| ②三段师承传功 | 三个"市井小人物"高人，都住面馆半径 500 米内，最后都死/离场。 |

| ④双力量合一=主题+预言句 | 能力本质是 **"声"（连接/共情/扩音）与"寂"（隔绝/终结/吞声）合一**。开篇密码句：**"这座城市要塌下来之前，会先安静下来。"** 结尾应验。 |
| ⑤至亲之死驱动人格裂变 | **两波黑化**：老宋之死 → 第一次；小满之死 → 第二次。 |

| ⑦反派=至亲 | 幕后黑手是 **陈默以为早死的父亲**，他要发动"大静默"。 |
| ⑧反派动机有正当性 | 父亲认为"声音"是一切痛苦与谎言的源头，静默=慈悲。 |

## 三、能力设定（一句话讲得清）

- **能听见**：不是读心——他只"听"到一个人心里反复响、却绝不肯说出口的**那**一句话（叫"重音"）。
- **代价**：城市越吵他越痛，人多就耳鸣。所以他总戴耳机、话少（"闷罐"的由来）。
- **进化（三段式）**：
  1. **静耳**（老宋教）——学会**关掉**能力，自保与克制。
  2. **共振**（老关教）——把听到的"重音"转成自己的力量。
  3. **合一**（老穆灌顶）——"声"与"寂"在他身上第一次合流，能力质变。

## 四、人物表（出场刻意压到最少，控成本）

| 角色 | 身份 | 结构职能 |
|---|---|---|
| **陈默**（闷罐） | 面馆少东家 / 外卖骑手 | 主角 |
| **老宋** | 收废品的瘸腿老头（听风会叛出的"静耳人"） | 师傅①，教"静耳"，**第一次黑化的触发者** |
| **老关** | 夜班黑车司机（寂声局"封口人"） | 师傅②，教"共振" |
| **老穆** | 楼上盲人调音师（两派共同祖师级） | 师傅③，灌顶传功、点破身世 |
| **苏晚** | 女刑警，因连环"失去声音"案查到他 | 正主，感情主线 |
| **小满** | 聋哑女孩，面馆常客，用纸笔和他交流 | **遗憾支线**，能让陈默"不听也能懂人"，**第二次黑化的触发者** |

## 五、三幕骨架（适配短篇 1.5–2 万字 / 漫剧 12 集）

**第一幕 · 重音（建立 + 第一次推力）**
- 开场写穷与善：面馆赊账、他送外卖替人挨骂、他捂住耳朵蹲在街角。
- 异常事件：他"听见"一个陌生人心里的重音——那句"我要杀了他"——然后那人真的动手了。命运第一次推他。
- 老宋登场，教他"静耳"（关掉能力），引出"这城市有人在悄悄收走声音"。

**第二幕 · 共振（升级 + 第一波黑化）**
- 老关登场，教他把"重音"变力量；苏晚查案接近他，从怀疑到并肩。
- 小满线铺开：唯一"没有声音"的人，他第一次觉得安静。
- **中点爆点**：老宋为护他，被两派灭口。→ **陈默第一次黑化**：他用"寂"把一整条街变成死寂（对应"血洗总督府"的功能位）。

**第三幕 · 合流（第二波黑化 + 决战）**
- 老穆灌顶，声与寂在身上合一，点破身世。
- **第二波黑化**：小满死 → 能力失控，整座城市要被"静音"，密码句应验。
- **决战**：反派浮现=父亲，大静默发动。父子对立的伦理两难。
- **收束**：陈默靠"合一"阻止大静默，但**不杀父亲**——他用能力"听见"了父亲这辈子一直没说出口的那句重音（对应原书"用善良赢回来"的母题）。面馆重新开张。

## 六、黄金三章怎么开（照引擎的开篇法）

1. **第 1 章「闷罐」**：先立"穷"和"善"——他给流浪汉赊账、捂住耳朵蹲在街角。**先让读者同情。**
2. **第 2 章「重音」**：给"异常事件"——他听见一句"我要杀了他"，然后事真的发生了。**命运第一个推力。**
3. **第 3 章「收声音的人」**：老宋登场，抛出世界规则与悬念（有人在收声音）。**同一种"被命运推着走"的模式，第一幕内重复一次。**

## 七、这套骨架为什么省钱、好改编

- **场景**：面馆、城中村小巷、夜班车、警局、旧楼道——**5 个主场景**，全是实景级，AI 漫剧分镜复用率高。
- **人物**：常驻 7 人以内；打斗可以有"无声"流派（用声音的"消失"做视觉，比大场面更省更亮）。
- **反转密度**：身世谜、父子局、两次至亲之死——短篇体量刚好塞满。
- **差异化**：都市异能常见"拳头/元素"，这里主打 **"声音"**——听觉系的视觉表达（波形、静止、耳鸣、纸笔交流）在漫剧里天然出记忆点。

## 八、待你拍板的三件事

1. **体量**：先写短篇（1.5–2 万字，冲番茄短篇/知乎盐选）还是直接铺长篇？
2. **能力调性**：听觉系保留，还是换成你更顺手的（视觉/记忆/运气）？
3. **结局温度**：按"父子和解、不杀"的暖收，还是"必须杀父"的冷收？（暖收更适配当下短剧情绪，冷收更硬核）
