# 移植对照表：三角洲行动 → 《观火》（武侠版）

## 一、这一版换的是什么

末世版《潮账》换的是"世界"，保留的是"结构"。武侠版同样只搬结构，但多了一件事：**把"技术"换成了"手艺"**。

三角洲的麦高芬是一块能改写格局的技术核心；在武侠里，这个位置最合适的东西不是秘籍，而是**铸法**。

理由：秘籍只改变一个人，铸法改变一个国家的武力秩序。前者是爽文，后者是权力。

## 二、逐项映射

| 三角洲原设定 | 《观火》设定 | 改了什么 |
|---|---|---|
| 阿萨拉 | **大梁·江北道**，二十年前"丙申之变"的旧地 | 从异国战区改成自家一块被抹掉的旧地 |
| 零号大坝 | **老炉山**（前朝百炉监所在，封了二十年） | 单点、易守、有库、有闸，功能位不变 |
| 哈夫克集团 | **盛记铁号（盛氏）** | 从科技财团改成掌盐铁漕运、私铸兵器的巨贾 |
| 曼德尔砖 | **百炉谱**（七卷，散落各处） | 从一块技术核心改成**铸法**：能重铸天下兵器，含火器之法 |
| Relink 脑机实验 | **试火** | 铸谱之法必须有人站在炉前看火色；看错一次瞎一只眼，看错三次死。历代匠师皆盲 |
| GTI | **镇抚司**（缉事衙门，"代天巡狩"） | 名义上查私铸，实际在抢谱 |
| GTI 高层内鬼 | **裴廷**（镇抚司指挥使，与盛氏通） | 双重身份：既替朝廷办事，也替盛家递消息 |
| 阿萨拉卫队 | **山河会** | 丙申年被诛匠户的后人与江湖残部，占废矿、山口、渡口，散成几股 |
| 雷斯 | **雷九**（占老炉山山口，父亲死于丙申夜） | 保留"为父守一块地"的内核 |
| 红狼 | **郑铎**（盐运司押运副使） | 动手的人，最早怀疑主角的人，也是最后替他挡刀的人 |
| 搜打撤 | **开山三日**：进山—搜库—赶在闭山梆子第九声前出闸 | 机制内核完整保留，外壳换成山禁 |
| 撤离点 | 水关（石梁、暗渠）、前山栈道 | 每个口子有自己的"关门方式" |
| 保险箱 | **火漆封条**（编号+司印，当众上漆、盖印） | 值钱的东西必须当众封、当众签，这是全书的破案工具 |
| 背包容量 | 背篓与山道：背重了走不了 | 拿多了会死，不用任何数值 |
| 干员技能 | 江湖手艺：辨火色、听炉、认锈、看断口新旧 | 技能改成**经验**，不给内力不给轻功 |

## 三、必须死守的三条

1. **三方都不干净。** 盛氏在铸兵也在养活半个江北的匠户；镇抚司在缉私也在灭口；山河会在守山也在收买路钱。
2. **麦高芬能改写格局。** 百炉谱不是一堆值钱的铁，是"谁拿到谁就能让一个国家的刀剑在三年内全部换代"。
3. **撤离有硬时限。** 闭山的梆子敲到第九下，闸就落。所有紧张感压在这九声上。

## 四、必须丢掉的三样

1. **内力、轻功、点穴这套武力系统。** 主角不会武功，全书也不给任何人"一掌震飞十人"的场面。武力必须有重量：一刀砍下去人会累，会喘，会死。
2. **现代术语。** 没有"战术""参数""标准件"。全部换成当时的说法：火候、成色、炉温、走水、退火。
3. **"江湖"作为浪漫。** 这书里的江湖是产业链：矿、炭、炉、盐、漕、账。侠客是这条链上的打手。

## 五、金手指（三层，与末世版同功能位，不同质感）

| 层 | 能力 | 说明 |
|---|---|---|
| 第一层（明） | **账**。龙门账、四柱清册、对单、追引、查空饷 | 全书爽点主力。不靠武，靠专业碾压 |
| 第二层（半明） | **眼**。看火色、看铜铁成色、看刀口新旧、看纸与漆的年头 | 他总能看出"这东西不对"，说不出为什么。所有预警都从这里来 |
| 第三层（暗） | **他的眼睛本身就是第七卷** | 当年匠师把辨火之法用"过火"烙进一个幼童眼底，看七十七种火色，烧出纹路。那个孩子就是他 |

第三层解释（第三、四卷回收）：百炉谱第七卷从来没有写过纸。它刻在一个孩子的眼底。

这一改同时解决四件事：

- 金手指不依赖"玩过游戏"，而且**能力与麦高芬是同一个东西**
- 代价机制天然：眼力用一次损一分，他不是忘，他是**慢慢看不见**
- 三方要的不是"找到第七卷"，是"抓到那个活着的人"，麦高芬因此有体温
- 终局的选择题极狠：**要取出第七卷，就得把眼睛烧掉**

## 六、与末世版《潮账》的差异（避免两本同构）

| 维度 | 潮账（末世） | 观火（武侠） |
|---|---|---|
| 麦高芬 | 潮芯＝七个活人 | 百炉谱＝七卷，最后一卷在主角眼里 |
| 代价 | 每调一次，记忆掉一层 | 每用一次眼力，视力损一分 |
| 主角的暗线 | 别人记忆的容器 | 活着的第七卷 |
| 第三方 | 守潮人（军阀化的自救队） | 山河会（匠户后人＋江湖残部） |
| 撤离钟 | 潮涨、闸落 | 闭山梆子九声 |
| 死人数错位 | 他记得的第三个名字不是老曹 | 第三个死者二十年前就在死册上 |

## 七、命名速查

- 朝代：大梁；当下为承平二十三年
- 旧事：**丙申之变**（二十年前百炉监被诬私铸、一夜封炉诛匠，进山三百一十七人，出山一百零四人）
- 禁地：**老炉山**；山口铁闸；每年**开山三日**
- 组织：盛记铁号 / 镇抚司 / 山河会
- 人要：简行（书算）、郑铎（押运副使）、小六（学徒）、张铁（弩手）、程九（老卒）、裴廷（指挥使）、盛维岳（家主）、雷九（山口把头）
- 物件：关册、印盒、火漆、背篓、铁样、梆子
- 技能：辨火色、听炉、认锈、看断口
- 书内常用语：**盖了印的才算数**
