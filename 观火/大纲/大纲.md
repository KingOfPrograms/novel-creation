# 五卷总纲

**书名**：观火
**体量**：五卷，约 120 万字
**类型**：武侠 / 权谋 / 匠作 / 职业流（账房）
**一句话**：盐运司一个不会武功的书算，跟着验关队进封了二十年的老炉山清点旧库，第一趟他就数出账外一个人，第一具尸体背后刻着盛记的印。

## 卷一《开山》（1-60 章）

- 时间：开山三日，加回城之后二十天
- 起点：盐运司书算，随队核账，连刀都没摸过
- 终点：被调进镇抚司做"清册"，手里有第一份对不上的账，身上有第一个因他而死的人
- 核心事件：验关队进老炉山取三十七箱铁样，栈道遇伏，十人进山六人出；他靠"封条漆是新的"预警了库房有变，只救下一半人
- 卷末兑现：他从涂掉的墨底下看出"并携一人出"，并发现签字格里已经盖着盛记的印

## 卷二《火漆》（61-120 章）

- 核心事件：他追那枚盛记的印，从火漆的颜色查到一批"封了又开、开了又封"的箱子
- 中点反转：把他调进镇抚司的正是裴廷，理由是"你看漆的眼神，像我认识的一个人"
- 第一次设局：用封条编号做局，让盛记的人自己开了一箱不该开的铁样
- 代价：郑铎被派去一次"例行押运"，中伏，死了两个弟兄
- 卷末：他被停职查办，证据是他自己盖过印的一张领炭单

## 卷三《炉腹》（121-180 章）

- 核心事件：为了查清"并携一人出"是谁，他必须再进一次老炉山，走到山腹最深处的旧炉
- 他第一次见到山河会的世界：匠户的后人不肯离开这座山，因为祖宗的手艺还在里面
- 雷九的账：这个"山口把头"的账比盐运司干净
- 卷末：他知道百炉谱是什么——不是一本书，是七卷散落的铸法，而第七卷从来没有落过纸

## 卷四《七十七色》（181-240 章）

- 核心事件：他被带到一位瞎眼的老人面前，老人摸他的眼眶，说"你还在"
- 真相第一层：丙申年冬天，七十七种火色被烙进一个六岁孩子的眼底
- 真相第二层：他左手虎口那道疤不是他留的；他认得山里每一条路，因为他曾被人抱着走过
- 卷末：他拿到第一份能呈堂的铸谱抄本，当场被调包；替他死的是小六

## 卷五《观火》（241-300 章）

- 三方同时动手：盛氏要独占，镇抚司要上交，山河会要重开百炉监
- 他必须回答的只有一个问题：一个为了被取出来才活下来的人，这一生算不算数
- 终局：他当众把七卷凑齐，又当众烧掉一卷。没有人拿到全部，也没有人失去全部
- 最后一笔：他在关册最后一页签上自己的名字，日期写的是他第一次进山的那天

## 数字线

10（账上的人数） → 11（他数出的人数） → 3（死的人） → 9（梆子九声） → 77（七十七种火色） → 1（第七卷，他自己）

## 三条不能破的线

1. 他不打。所有冲突靠规矩、靠借刀、靠"让别人需要他"解决
2. 三方都不干净，任何一方写成纯反派，这书的骨头就软了
3. 火器是禁忌。谁先动火器，谁就是在改朝换代

## 与《潮账》的关系

同一个结构，两个世界。要合写就写"同一批人投进两个世界"，要分写就各走各路。这一版的气质是**冷、慢、讲手艺**；末世版的气质是**湿、快、讲配给**。
