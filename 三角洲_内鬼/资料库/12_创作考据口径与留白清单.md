# 创作考据口径与留白清单

> **动笔前必读。** 这份文件解决三个问题：
> ① 哪些设定绝对不能改；② 哪些说法互相冲突、写作时怎么处理；③ 哪些地方官方是空白，可以放心编。

---

## 一、硬设定（不可改，改了读者立刻出戏）

1. **雅各布是哈夫克的创始人，哈德森是他儿子。** 两人不是同一个人，也不是兄弟。
2. **GTI 成立于 2018 年**，与阿萨拉内战、零号大坝竣工同年。
3. **曼德尔砖 2024 年问世**，发布会在长弓溪谷的**钻石皇后酒店**，被**雷斯**抢走。
4. **巴别塔 2025 年建成，1500 米，在巴克什**（海港城市）。
5. **零号大坝 2018 年竣工，历时七年**（即 2011 开工），在**乌姆河**上。
6. **Relink 脑机 2035 年才宣布研发成功**（但实验早已秘密进行多年）。
7. **卡尔·休斯顿 2032 年死于坠机/伏击**，红狼因此加入 GTI。
8. **罗米修斯死了**（为佐娅挡手雷），**渡鸦没死**（在潮汐监狱），**哈姆克没死**（被哈德森救走）。
9. **GTI 最大内鬼是特种作战司令部的高级指挥官**，红狼的直属上级，从 GTI 成立起就是哈德森的人。
10. **德穆兰的脑机是雅各布安排植入的**，术后性格大变，对哈夫克绝对忠诚。
11. **赛伊德最终放弃炸坝**，并放走了比特。
12. **阿萨拉的首都叫马尔卡齐耶**，元首称谓是"**素丹**"。

## 二、可以松动（按需调整，不算错）

| 项 | 说明 |
|---|---|
| 具体日期（月/日） | 官方大多只给年份。可以自由编，只要年份对 |
| 地名拼写 | Ahsarah / Asara、Baksh、Zarvat 等有多种拼法，统一一种即可 |
| 军衔与编制 | 官方不严谨，按需设定 |
| 距离、人口、面积 | 官方几乎没有数字，可自由设定 |
| 天气与季节 | 官方无明确季节设定 |
| 具体武器型号 | 游戏里有大量现实枪械，可自由取用 |

## 三、冲突项（写作时建议模糊化或二选一）

| 冲突点 | 版本 A | 版本 B | 建议 |
|---|---|---|---|
| GTI 全称 | Global Threat Initiative / 全球应急行动组织 | Global Terrorism Intervention / 全球反恐特勤组 | 小说里**只用英文缩写 GTI**，避免读者质疑 |
| 赛季编号 | S4=衔尾蛇 / S5=破壁… | S4=黑夜之子 / S5=潮汐监狱… | **一律用赛季名**，不用编号 |
| 大坝是否被炸 | 刀锋地图显示已决堤 | 主线里赛伊德放弃炸坝 | 可以写"另有一次决堤事件"或"局部溃坝"，别写"大坝被完全炸毁" |
| 雷斯抢的是真砖还是假砖 | 抢走一块核心砖 | 抢到的是模型/假砖 | 推荐"**他以为是真的**"——两边都成立，且更有戏 |
| 亚历山大·哈夫克是否曾任 GTI 首任秘书长 | 有资料如此 | 他与妻子 1993 年已死，时间线冲突 | **不采用**。风险太大，会推翻全书格局 |
| 德穆兰失去说话能力 vs 电子音说话 | 失去发声能力 | 用电子音/脑机发声 | 推荐后者（脑机代声），细节感更强 |
| 赛伊德村庄被谁屠 | 哈夫克资助的军头 | 明确指认哈姆克 | 推荐"哈夫克出钱、哈姆克动手"——两人都沾血，且能连上后续剧情 |
| 潮汐监狱层数 | 室内/野外/水下三层 | 地上四层 + 水下两层 | 写"地上四层、水下两层"更具体 |
| 无名是否为"实验体" | 是，唯一保留自我意识者 | 只是受过哈夫克军事训练的佣兵 | 两者可以并存：先当佣兵，后被证实是实验体 |

## 四、留白清单（最好的创作缝隙）

> 这些地方官方**明确没写**或**几乎没写**，编了不算改设定。

### 人物层
- **雅各布的私人生活、身体状况、是否曾动摇**。全书最大反派，却是最空的人。
- **哈德森的母亲**。完全没有。
- **德穆兰的女儿卡米**：只说"普通学龄女童，似乎不在阿萨拉生活"。她在哪？谁在养？她知道母亲变成什么样了吗？
- **尤瑟夫·法希姆的正面戏**。他自封素丹，却没有一场像样的戏。**这是最大的空白**。
- **纳西尔·哈达维博士**（渡鸦的导师）的下落。
- **莱拉**（纳西尔之女、反哈夫克派）：渡鸦因亲近她而落人口实。她后来怎么样了？
- **GTI 内鬼的真名**。官方只说是"特种作战司令部高级指挥官"。**这是全书最好的原创接口**。
- **GTI 秘书长利亚·斯坦因**：几乎无着墨。
- **巴希尔·瓦拉比退出集团后去了哪里**。前 CTO、反哈夫克、被德穆兰救过——他可以成为任何角色。
- **红狼的母亲**、**银翼的家人**、**蜂医的过去**。

### 组织层
- **GTI 的经费从哪来**、**谁在审计它**。← 主角的位置就在这里。
- **哈夫克的股东结构**。它是一家公司，公司有董事会。董事会知道暗星计划吗？
- **阿萨拉卫队的财政**。他们买二手武器，钱从哪来？谁在卖？
- **潮汐监狱的囚犯名册**。谁被关进去、谁被划掉。
- **哈夫币的发行机制**。谁在记账？

### 地理层
- **马尔卡齐耶（首都）**：官方几乎没写。可以整座城市自由设定。
- **阿萨拉的普通村庄、学校、医院、集市**：完全没有。整个国家的"日常"是空的。
- **乌姆河沿岸的渔村**（因大坝失业的那批人）。
- **摩格旧城区**（S11 新图，几乎无剧情）。

### 时间层
- **2018–2024 这六年**：大坝建成了，砖还没造出来。这六年发生了什么？
- **2025–2029**：巴别塔建成了，航天基地在建，Relink 刚立项。GTI 在干什么？
- **2032–2035 这三年**：卡尔死了，GTI 介入，然后呢？**这三年是全书最该填的空白。**

## 五、命名与文本规范（保持一致性）

1. **人名统一用"名·姓"的西方顺序**：凯·席尔瓦、王宇昊（中国名不倒置）。
2. **阿萨拉人名用阿拉伯语系转写**：尤瑟夫·法希姆、哈立勒·雷斯、赛伊德·齐亚腾、伊塔克·宾·迪万·阿尔·法海穆。
3. **"素丹"不写作"苏丹"**（避免与国名混淆）。
4. **组织名首次出现给全称，之后只用缩写**：全球应急行动组织（G.T.I.）→ G.T.I.
5. **技术名**：曼德尔砖（首次可加注"ERAIS"）、Relink 脑机、天网、暗星计划、蝉颤系统。
6. **货币**：哈夫币（不要写"三角币"，那是玩家俗称）。
7. **地名**：零号大坝、长弓溪谷、巴克什、航天基地、潮汐监狱、扎尔瓦特古城、断层地区、宝石湾、摩格旧城区。
