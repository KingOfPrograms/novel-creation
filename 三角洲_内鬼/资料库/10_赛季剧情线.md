# 赛季剧情线（S1 – S11）

> **重要提示：赛季编号在不同资料里有错位。**
> 原因：国服/国际服赛季命名不同、玩家习惯用"赛季名"而非编号、部分媒体把上线顺序与赛季编号混用。
> 本文件给出**两套常见口径**，写作时建议：**用赛季名（起源、焰火、回声…）而不是编号**，这样永远不会写错。

---

## 一、主线骨架（不依赖编号的版本）

整条主线只有一个主题：**天网的诞生、迭代与武器化**。

1. **假砖骗局** — 哈夫克在钻石皇后酒店开发布会，雷斯抢走一块假砖/模型。真实目的是掩盖航天基地卫星发射进度。GTI"飞升者行动"赶去阻拦，情报缺失，失败。
2. **脑机线开启** — GTI 调查巴别塔的罗米修斯脑机项目，佐娅刚混入就被合围，撤退路线完全暴露（第一次明确的"内部泄密"信号）。
3. **焰火行动（雷斯反击）** — 雷斯通过线人"影子"拿到真砖，攻入航天基地操控火箭，主动撞击天网卫星。卫星如陨石坠落，城市通讯中断。他以为摧毁了天网——实际击毁的全是老旧初代卫星，哈夫克借混乱完成第二代部署，并在战役结束瞬间瘫痪 GTI 全部通讯。
4. **无名登场** — GTI 全线失联，实验体"无名"主动交易：帮他摘除脑中 Relink，他入侵天网终端恢复通讯。首次揭露天网能读取、干预、清除人类意识；近百名实验体意识被吞噬。
5. **潮汐监狱** — 渡鸦借暴动曝光"天网 + 气象武器"的秘密。但**他刻意隐瞒了空间站意识实验**。
6. **内斗** — 哈德森架空老太、接手哈夫克大权；老太组建"反哈联盟"，哈夫克公开分裂。
7. **内鬼曝光** — 回响用声纹锁定 GTI 特种作战司令部的高级指挥官：他从 GTI 成立初期就是哈德森安插的卧底。S1 以来的每一次失利都是他遥控的。红狼父亲之死的真相浮出。
8. **暗星** — 哈德森把 AZ3 核电站与天网绑定，核能提供无限能源，气象、地质、导弹、脑机四大系统闭环。
9. **群星（S11）** — 剧情回到潮汐监狱与典狱长，收束阿萨拉支线。

## 三、口径 B（另一套常见排法，供交叉核对）

部分资料把顺序排为：S1 起源 → S2 聚变 → S3 焰火 → S4 黑夜之子 → S5 潮汐监狱 → S6 烈火冲天 → S7 阿萨拉 → S8 蝶变 → S9 回声 → S10 裂变 → S11 群星。
另有一套（按"事件"而非"赛季"）把衔尾蛇行动归入 S4、鼠疫行动归入 S5。

**【结论】** 编号会错，**事件顺序不会错**：
假砖 → 脑机调查 → 撞卫星 → 无名 → 监狱 → 山火 → 炸坝 → 内斗 → 内鬼 → 核能闭环 → 群星。

## 四、可用的"官方已发生"清单（写书时不要写反）

1. 2024 年雷斯在钻石皇后酒店抢砖，是真的发生了。
2. 雷斯发射火箭撞卫星，是真的发生了；他撞掉的是旧卫星，反而帮了哈夫克。
3. 哈姆克被 GTI 围剿、坦克被毁、本人重伤，确实发生了；但他**没死**，被哈德森救走。
4. 罗米修斯**死了**（为佐娅挡手雷）。
5. 渡鸦**没死**，被关在潮汐监狱。
6. 赛伊德**没死**，放弃炸坝，后来成为可操控角色。
7. 银翼**离开了 GTI，又回来了**。
8. 哈德森**是**幕后黑手，且**是**雅各布的儿子。
9. GTI 最大内鬼是**特种作战司令部的高级指挥官**（红狼的直属上级），姓名官方未公开。
10. 德穆兰**没有死**，S11 还能被玩家扮演。

## 五、写作提示

1. **本书时间点建议卡在 S8–S9 之间**：内鬼已经浮出水面，但还没有全面曝光；哈夫克正在内斗；暗星还没闭环。这个窗口"所有人都在动，但结局还没定"，最适合插入原创主角。
2. **绝对不要写"主角阻止了焰火行动"**——那是威龙的高光。可以写"主角在焰火行动里负责一件小事"，然后让这件小事在三年后变成关键。
3. **不要把官方干员的结局改掉**。可以让他们在主角的线里"路过"，但不能替他们做他们该做的事。
4. **最好的插入方式**：主角处理的是**账目、补给、通讯日志**——这些官方剧情从来不写的部分，正好是"泄密"真正发生的地方。
