# 地标与地图：烽火地带（搜打撤）

> 烽火地带 = 游戏主 PvPvE 撤离模式。每张图既是玩法场，也是**剧情现场**。
> 写法建议：把地图当"舞台说明书"用——区域划分 = 幕次，撤离点 = 出口，BOSS 出没地 = 高潮点。

---

## 1. 零号大坝（Zero Dam）

**【官方】**
- 世界最大水力发电装置，阿萨拉乃至全球的"伟大工程与建筑奇迹"。
- 由前国王**迪万·法海穆**委托哈夫克建造，历时七年，**2018 年竣工**。
- 部署**世界上第一块曼德尔砖**作为处理核心，由 **ERAIS** 原型版调度，为全境供水供电。
- 原规划为全国主要旅游中心，内战使一切停滞，现被**阿萨拉卫队完全控制**，由**赛伊德**驻守。
- 库区建设强制移民，下游渔民失业。

**【整理】区域与玩法**
- 核心区：行政楼（行政辖区）、水泥厂、军营、主变电站、游客中心、地下金库、浴场撤离点、巴别塔前撤离点
- 水泥厂与军营产基础物资；主变电站与行政辖区有保险柜、地下金库等高价值物资
- 撤离需**拉闸**激活；地下通道贯穿全图，适合快速转移与伏击
- 新手图，难度低、容错高

**【剧情锚点】**
- 赛伊德在**行政楼**出没；夜战模式下可能在**大变电站**出现。他活着时进行政楼会听到专属 BGM，他死时 BGM 立刻切到结尾并迅速结束。
- 雷斯曾蛊惑赛伊德炸坝（S7 剧情），被 GTI 干员比特劝止。
- 全面战场版"**刀锋**"就是**决堤后**的零号大坝，战场在坝体顶上，能看到被洪水淹没的水泥厂和行政楼。

**【写作可用】**
- 大坝是全书的水源、电源、机房、坟墓。写"水声"就是写"控制"。
- 坝体内部的机房温度、噪音、震动，是极好的密闭空间戏舞台。

## 2. 长弓溪谷（Layali Grove）

**【官方】**
- 曾是阿萨拉**土著民族的保留地**，风景秀丽，旅游资源丰富，有火车站、码头、豪华宾馆。
- **2030 年**阿萨拉濒临破产，哈夫克收购债务控制全国；**预测型 AI 判定长弓溪谷不值得拯救**，大部分地区被放弃，只有西北部的雷达站、火车站等固定资产保留。
- 被放弃的区域现由**阿萨拉卫队**占领，**雷斯**控制。

**【整理】区域与玩法**
- 面积最大的山地地图，地形起伏，河流贯穿，分上下半区
- 核心资源区：**钻石皇后酒店**（连锁豪华酒店）；加尔比旧址（医疗物资）；沙径牧场（工具材料）；**哈夫克雷达站**（高风险高回报）
- 阿米娅小镇高塔是绝佳狙击位；河道两侧高处视野开阔，适合远程
- 中心撤离点需穿越开阔地带
- 玩家定位："老六天堂"，狙击与蹲点

**【剧情锚点】**
- **2024 年曼德尔砖发布会就在钻石皇后酒店**，雷斯带队突袭抢砖——全书起点。
- 雷斯出没于**钻石皇后酒店**或**哈夫克雷达站**。他出现时附近有播放歌剧的录音机；若出现在雷达站，主楼入口会有大量哈夫克士兵的尸体，且主楼内不刷哈夫克士兵（说明他刚血洗了那里）。
- S6"烈火冲天"：**长弓山火**事件，GTI 追查曼德尔砖藏匿点被"黑曼巴小队"精准截胡。
- S11：**长弓溪谷 2.0** 重做，南部水域全开，可游泳、开摩托艇/攻击艇，新增"世外桃源"区域与钓鱼系统。

**【写作可用】**
- "被 AI 判定不值得拯救的地方"——这句话本身就是一整章。
- 酒店是最好的密闭戏舞台：宴会厅、国王房、后台、厨房、地下车库。
- 山火 + 河流 = 天然的追逃地形。

## 3. 巴克什（Baksh / 巴别塔）

**【官方】**
- 阿萨拉重要**海港城市**，哈夫克集团**总部驻地**。
- 市中心矗立 **1500 米**的世界最高建筑——**巴别塔**（哈夫克尖塔），2025 年建成。
- 哈夫克的设计理念：科技与本土文化结合、接纳各行各业人群、构建和谐社会风貌；以巴别塔为起点进行城市改造。街道、城墙有浓厚历史气息，城内露天市场星罗棋布。
- 2035 年内乱使改造中断，城市**一分为二**：新城区由哈夫克掌控，老城区被阿萨拉卫队占领，沦为割据地带。

**【整理】玩法**
- 地图小但结构复杂，巷战密集，被高墙分南北两区
- 南部**巴别塔**是核心高价值区，大红爆率高
- 撤离方式多：拉闸、丢包、身份牌、博士（护送 NPC）
- 唯一可用"精锐券"进入绝密模式的地图
- 玩家定位："巷战绞肉机"、"刮地皮首选"

**【剧情锚点】**
- 巴别塔 = 哈夫克的权力象征，也是"巴别塔行动"的名字来源。
- 塔外的哈夫克士兵与塔内不同（塔内仍会攻击玩家），暗示塔内是另一个体系。
- 露天市场、老城墙、新城玻璃幕墙——**一墙之隔的两个时代**。

**【写作可用】**
- 巴别塔是全书最好的"垂直舞台"：1500 米，从上到下是不同阶层、不同权限、不同谎言。
- 名字本身是隐喻：人类造塔通向神，神把它推倒。

## 4. 航天基地（Space City）

**【官方】**
- 原是阿萨拉破败的**国有航天中心**。
- **2022 年**哈夫克与阿萨拉政府达成协议，把航天中心用于发展**小行星采矿技术**。
- 翻新 **2029 年**竣工，但**开幕典礼遭阿萨拉卫队袭击，伤亡惨重**（德穆兰在此毁容）。
- 袭击未阻挡哈夫克：强化安保、全面控制后，航天城飞速运作，各类卫星被送入轨道，满载的火箭定期落入阿萨拉沿海区域并被迅速取回处理。
- 现由**德穆兰**镇守。口号："天空属于哈夫克。"

**【整理】区域与玩法**
- 发射区、工业区、主楼、码头。核心区：蓝室、黑室、总裁室
- 码头红房固定刷新绝密服务器；水下管道低概率产出风暴机甲容器
- 天桥与北部中控楼是关键制高点
- 撤离需穿过哈夫克雷达站信号屏蔽区；需门卡
- 玩家定位："练技术首选图"，高压对抗
- S8 重做后新增滑索、水下区域

**【剧情锚点】**
- 天网卫星从这里升空。
- 罗米修斯的 Alpha 脑机发布会在这里（被哈姆克派兵突袭）。
- 勇敢者行动：哈姆克以"逃生"为名，骗 GTI 和卫队把**暗星燃料**送上火箭，直送空间站。
- 全面战场"**攀升**"：GTI 以"哈夫克窃取资源、私建军备"为名对攀升地区发起登陆战，目标是山顶尖塔。
- 全面战场"**风暴眼**"：哈夫克重启冷战遗留导弹基地，与天网闭环。

**【写作可用】**
- "天空属于哈夫克"是一句可以反复打脸的台词——每一次火箭升空，都在把这句话变成事实。
- 发射台的倒计时是天然的叙事节拍器。

## 5. 潮汐监狱（Tide Prison）

**【官方】**
- 哈夫克私人**孤岛监狱**。
- 关押**渡鸦**；典狱长是**格赫罗斯**。
- 哈夫克在此用平民做 **Relink 脑机活体实验**，大量民众惨死。
- 关押者被强制佩戴脑机，处在哈夫克监视之下。

**【整理】玩法**
- 分室内、野外、水下三层（另有资料称地上四层 + 水下两层）
- **进入时无初始装备**，需通过任务与解密获取装备
- 水下可修甲打药、队友救援，但只能使用近战武器
- 全图只有一个拉闸点，三个撤离点随机开启，另有免费倒计时撤离点
- 玩家定位："爆率天花板"、立体迷宫

**【剧情锚点】**
- S5"破壁"：GTI 突袭潮汐监狱抓渡鸦，情报有误、潜入计划被全盘掌握，伤亡远超预期。
- S7：渡鸦煽动囚犯暴动，监狱内 GTI 探员、哈夫克守卫、阿萨拉俘虏三方混战，曝光哈夫克非法关押平民、酷刑逼供。
- S11"群星"：剧情围绕**典狱长与潮汐监狱**展开，典狱长回归。
- 格赫罗斯背景：前 GTI 特种小队队长，因追查上司武器走私并反水被通缉，受哈夫克招募镇守此狱，信条"秩序审判"，口号"罪恶必将接受制裁"。

**【写作可用】**
- 监狱是全书"制度"的实体化：谁被关、谁在看守、谁在记录。
- "进监狱先没收装备"这个机制，本身就是极好的剧情设定：主角赤手空拳进岛。
- 水下段落适合写"听觉恐怖"——看不见，只能听。

## 6. 扎尔瓦特古城（Zarvat）

**【官方】**
- 阿萨拉东部古城，百年前是水陆交通枢纽。
- 零号大坝建成后河流水位下降，失去地位，逐渐衰落。
- 现由**哈姆克**控制。
- **衔尾蛇行动**中，古城在 GTI 与哈姆克的激战中**毁于战火**。

**【写作可用】**
- 一座"因为修了大坝而渴死"的古城——基建的代价具体化。
- 已被摧毁，所以适合写"战后回访"、废墟、记忆。

## 7. AZ3 核电站（S10 新图）

**【整理】**
- 最初由阿萨拉王室与哈夫克合资建造，内战爆发后被哈夫克完全接管。
- 阿萨拉卫队视整座电站为卖国产物，常年突袭；曾炸毁**初代核电站**造成大面积辐射污染。
- BOSS：**毁灭者 H1000**（哈夫克弃子式安保单位），掉落"AZ3 密钥"。
- 若对局触发核爆结局，哈夫克会直接放弃电站撤离，毁灭者仍死守到最后。
- S10"裂变"：哈夫克启动**暗星计划**，把 AZ3 与天网绑定，核能为曼德尔砖提供无限能源。

**【写作可用】**
- 核电站是"技术垄断走到尽头"的样子：为了无限能源，赌上所有人的命。
- 弃子式安保——"公司会走，机器会留下"，这句话可以给任何一个哈夫克中层当临终台词。
