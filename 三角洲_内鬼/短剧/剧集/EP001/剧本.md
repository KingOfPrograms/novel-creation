# EP001《九分钟》

- 形态：横屏 16:9｜时长 12-13 分钟
- 时间窗口：距巴别塔行动 72:00 - 66:00
- 地点：全部在**零号大坝**一张图内（河滩 / 坝体下方 / 货运梯 / 库房 / 闸房 / 铁桥 / 驳船）
- 主要人物：陆沉、霍尔、帕特、小裴、阿依莎（遗体）、红狼（末场）

---

**1. 外景 坝下河滩 夜 05:52**

字幕卡：距巴别塔行动 72 小时

黑场。水声。

画面亮起来的时候，是齐膝深的河水。八个人影排成一线，慢慢往岸上挪，谁也不说话。

陆沉在队伍中间。他走得很僵，左脚踩进一块松动的石头，身体往右歪，被后面的人扶住。

帕特（低声）：别出声。

陆沉站住。他低头看自己的手。

左手虎口，一道旧疤。

他把手翻过来，又翻回去。

**2. 外景 坝下河滩 夜 05:54**

所有人蹲在石滩上。头顶远处，坝顶的探照灯慢慢扫过来。

所有人一起低头。灯过去。

陆沉摸胸前，摸到身份牌。他把它翻过来，借着远处的灯看。

特写：陆沉｜GTI 阿萨拉战区｜情报组｜见习分析员

陆沉（低声）：陆沉。

他抬头，看周围的人。

霍尔（O.S.）：报数。

一，二，三……

数到第七个，是陆沉。

陆沉（慢半拍）：七。

八。这个声音很年轻，是昨天才发下来的新兵，姓裴。

九。最后一个数完，那人补一句：九个，齐了。

陆沉在心里又数了一遍。九个，加带队的一个，十个。

**3. 外景 坝体下方 夜 05:58**

队伍贴着坝体往前走。坝很高，往上只能看见一小块天。

走了大概两百米，陆沉忽然停住。

他抬头看坝顶。

探照灯左边，第三个墩子的位置，有一点白亮，一闪，没了。

陆沉：坝顶有人。

前面的人回头。

陆沉：第三个墩子。刚才有反光，白的。

带队的人（帕特）看了三秒。

帕特：分析员。你眼神挺好。

有人低低地笑。

陆沉：东侧楼梯不能走。他架在那儿，就是为了打东侧楼梯。

帕特：那走哪儿。

陆沉：西侧。货运梯，慢，但看不见。

帕特把手电按在腋下，借反光看手上的地图。纸边磨毛了。

帕特：分两组。我带四个走东侧，五分钟以后库房门口会合。

陆沉：不能分。

帕特：为什么。

陆沉张了张嘴。他说不出来。

陆沉：我记不清。但我知道会死人。

安静。水从坝体上滴下来，落在石头上。

帕特看了他一眼，那一眼很短，像在估一件货能值多少钱。

帕特：你叫什么。

陆沉：陆沉。

帕特：干什么的。

陆沉：查账。

帕特把地图折起来，塞进胸前口袋。

帕特：查账的。账我认，人我不认。

他抬手一挥。

帕特：东侧，走。

四个人跟着他走了。

抱枪老兵把烟从嘴角拿下来，没点。

老兵：小子。下次想说这种话，先想好怎么说。

陆沉：我没有下次。

老兵笑了一下，把烟别回耳朵上。

**4. 内景 货运梯 夜 06:03**

铁梯一层一层往上盘，全是水，踩上去滑。

小裴跟在陆沉后面，手抖得扶不住扶手。

走到第四层，东边响了。

先三声，很脆，间隔一样长。然后一串，闷的，像有人在铁皮棚里撒了一把石子。

霍尔停住。四十来岁，下颌一道旧疤，军服外头套着件脏得看不出颜色的马甲。

他抬手，所有人贴在墙上。

东边的枪声停了两秒，又响了一次，只有一声。

然后就没有了。

霍尔把手放下来，继续往上走。

没有人问。

**5. 内景 库房 夜 06:08**

双开铁门，锁被撬过，撬痕是新的。

霍尔推门。里面码着箱子，整整齐齐。

他跟单子对，一项一项点。十四项，一项不少。

霍尔：搬。

搬东西。陆沉搬的是两个方箱子，不重，但沉手，像里面灌了沙。

第三趟，他在最里面的角落看见一个人。

那人靠墙坐着，头低着，双手放在膝盖上，像睡着了。枪横在腿上，枪口朝自己。

陆沉：这里有一个。

霍尔过来，蹲下，把那人下巴抬起来。很年轻，脸上有灰，眼睛睁着，瞳孔是散的。

霍尔：东侧的。叫阿依莎。

他把手放下来，在那人膝盖上按了一下，站起来。

霍尔：继续搬。

搬完，霍尔在门口回头看了一眼，关上门。

**6. 内景 闸房 夜 06:14**

三个老式铜柄开关，上面挂着手写牌子。

霍尔把中间那个往下压。

机器响了一声，很沉，像有什么东西在地底下醒过来。

霍尔：闸开了。九分钟。

陆沉：九分钟以后呢。

霍尔：九分钟以后闸自己合上。谁没过，谁留下。

**7. 外景 铁桥 夜 06:16**

撤离点在坝体北侧的水门。一条窄铁桥通到水面，桥头两盏灯，只亮一盏。

跑到一半，后面响了。

正后方，机枪，节奏很稳。

跑在最后的一个人扑倒，没起来。

霍尔：压制！帕特，压制！

帕特转身，把机枪架在水泥墩上，开始还击。

帕特：走！走啊！

陆沉跟着人跑。铁桥很窄，只能一个人过。

跑到桥中间，他回头。

帕特还在打。背后的水泥墩一片一片地掉灰。他换了一次弹链，第三次抬头。

坝顶那道白亮了一下。

很短的亮。

帕特往前扑，机枪从墩上滑下来，砸在地上。

霍尔一把扯住陆沉的领子，把他往前拖。

霍尔：别看！

**8. 外景 驳船 夜 06:22**

铁桥尽头是一条驳船，机器开着，船尾翻水花。

所有人跳上去。船立刻动了。

陆沉趴在船板上，回头。

坝顶那个位置，又亮了一下。

陆沉：九个进去的。

霍尔：六个。六个出来。

船开出约一公里。霍尔在船头坐下，从马甲内袋掏出一个黑壳本子，一支短得只剩半截的铅笔。

霍尔（念）：阿依莎。东侧，头部。

写完，划一道。

霍尔：老周。东侧，胸。

划一道。

霍尔：帕特。断后，坝底。

笔停住。他抬头往坝那边看。坝很大，黑着。

霍尔（又念一遍）：帕特。

写下去，划一道。

三道横线。

陆沉盯着那三道线。

陆沉（心里）：三个。我知道是三个。

陆沉（心里）：可我记得的第三个不是他。

画面插一帧：食堂，一勺汤，一把放下的勺子，一圈在笑的人。看不清脸。

霍尔：你叫什么来着。

陆沉：陆沉。

霍尔写，写得很慢，一笔一划。

霍尔：哪个陆，哪个沉。

陆沉：陆地的陆，沉默的沉。

霍尔写完，在名字后头画了个问号，合上本子，塞回内袋。

霍尔：坝顶第三个墩子。你怎么知道的。

陆沉：我看见反光。

霍尔：我也看了。什么也没有。

陆沉没说话。

霍尔看了他一会儿，把耳机摘下来，挂在脖子上。

霍尔：哈德森先生会想跟你聊聊。

**9. 外景 码头 夜 06:26**

驳船靠上一条水泥栈桥。

栈桥上有个人在等。外骨骼没脱，右膝一圈旧护具。

红狼。

他没看人，先看箱子。他打开最上面那个方箱子，看一眼，合上。

红狼：少一个。

霍尔：少一个。

红狼：哪一个。

霍尔：人少了三个，货没少。

红狼停了一下。

红狼：哪三个。

霍尔翻开本子，念了三个名字。

红狼听完，没说话。他转过头，看船上的人。

他的目光在陆沉身上停住。

红狼：你。

陆沉：我。

红狼走过来，抓住他的手腕，把他的手翻过来，一寸一寸看：掌心，指根，虎口。

红狼：没茧。你没开过枪。

陆沉：对。

红狼：没开过枪的人，怎么会抬头看坝顶。

陆沉（看着他）：直觉。

红狼盯了很久。旁边的人开始往这边看。

红狼（笑了一下）：行。直觉。

他松手，转身走，走几步停下。

红狼：我叫红狼。你记住这个名字，因为我大概会是你在这儿认识的第一个不信你的人。

**10. 外景 码头 夜 06:29**

陆沉站在栈桥上。风把水汽吹上来。

他低头，又看了一眼自己的手。

那道疤还在。

远处，三副担架从船上抬下来，一副一副过。

最后一副经过时，风把布吹开一角。

担架上的人手里攥着一张折起来的纸。

陆沉抬起头。

陆沉（心里）：三个名字。我记得两个半。

画面切黑。

字幕卡：距巴别塔行动 66 小时

## 本集要点（拍摄备忘）
- 全片不给陆沉的特写超过 3 秒，靠手、眼睛、背影演；恐惧只能从别人的反应里看出来
- 「报数」的镜头一次拍成，观众要能跟着数到九
- 帕特战死不拍中弹瞬间，只拍坝顶那点白光 + 机枪滑落 + 霍尔扯领子
- 三个死者用同一套处理：名字 → 划线 → 下一道，不加音乐，只留铅笔声
- 结尾那张纸不给内容，只给「折起来」和「攥着」两个动作
- 全片不出现飞机。进图靠涉水，撤图靠驳船
