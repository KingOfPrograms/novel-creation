# 世界设定归纳（S4）

## 力量体系

**层级、等级、晋升方式：原文未明确**（30 章内未出现任何等级名目）。原文呈现的是以下四组可观察规则：

### 1. 心声听觉（主角持有）
- 能听见别人心里没说出口的那句话；不挑时候、关不掉（ch1）。
- 耳机音量盖不住——它不是声音（ch2）。
- 可"对上人"：心声与具体的人当场对位（ch3 首次）。
- 过重的心声听不清："心里有一样东西太重的时候，它自己会往下沉"（ch18、ch26）。
- 可训练控制：比喻为"门没关严"（ch10）；三步口诀——手按心口、动静往下沉、念"这是我的"（ch13）；心跳是"谁也拿不走的"锚（ch28）。
- 代价：听见了就装不了没听见（ch1 起）；"拔不出手"（ch23）。

### 2. 收声（敌方持有）
- 他人的声音可被"收走"：不是"抹"（毁掉），是"收"（拿走），拿走的东西"大概还能放在别的地方"（ch23，主角推断）。
- 表现形式：整段环境静音（ch6 全街、ch29 整巷）、声音"矮半格"（ch17 碰灶台）、个人失声（ch28 吃掉喊声）、无声脚步（ch15、ch28）。
- 规律：先静后哑——出事者先"心里静"约一个月，后才哑（ch19 推出、ch27 方法论交付）。
- 失语三件套：当事人报不了案、旁人看不见伤、医生查不出病（ch23）——三样凑齐，一件事"可以永远不发生过"。
- 被收者无法自察（ch23：他连报案都报不了，没法描述一件发生在自己心里的案子）。

### 3. 破收声之法
- 制造回音与杂声：铁皮桶砸铁门的"回音"像针扎破局（ch29）；报警器、垃圾车倒车音、醉汉跑调歌搅乱收声（ch28）——"乱了，他就收不住了"。
- 护住心跳、拿它当墙（ch28–29）。

### 4. "空"（镜像谜题）
- 老宋心里是空的（ch3）；秦九心里"干净得只剩'办完就走'"、没有"我"字（ch28）。两者同构，含义原文未明——师与敌共享同一种"空"，是全书最大的世界悬念之一。

## 特殊设定

- 被收者当街失语时，计价器还在跳（ch23）——"收"只针对人与声音，不针对机器（漫剧招牌细节）。
- 面馆被老宋判定"不干净"（ch10）：声音在店内被捻灭过一次，所指原文未明（有遗留物？有人来过？）。
- 声控灯、卷帘门、雨棚铁皮、板车吱呀等市井声响在本作中承担"活着"的证词功能（ch6、27、28）——声音本身是半个角色。
- 陌生人可用一通电话报出主角母亲的名字并声称持有"她留下的那样东西"（ch29）——敌方情报深度远超预期，原文未解释来源。
