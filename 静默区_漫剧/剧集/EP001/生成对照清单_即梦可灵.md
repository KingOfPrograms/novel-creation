## 一、先说结论（默认路径）

图片（6 资产板 + 19 关键帧）**已经全部落盘**在 `剧集/EP001/制作成果/images/`，直接用：

- 跑视频 = 上传对应关键帧 PNG 当**首帧**（首尾帧镜头再加一张收尾帧）→ 复制 MOTION 可复制提示词 → 选 16:9 → 生成。
- 保角色一致 = 对白镜把对应**人物资产板**一起当参考图上传（即梦「图生图/参考图」，可灵「元素参考 element reference」）。
- 需要重出某张图 = 复制 IMG 提示词，两平台「文生图」跑即可。

## 六、剪辑合成去向

两平台生成完，统一进剪映合成：先导样片 18 镜按镜序排列 → 叠加心声双轨字幕（下三分之一安全区：左轨嘴上、右轨心声）→ 贴配音（选型已定音色）→ 死寂段静音轨 + 面落锅声桥。片长约 75 秒（对白/心声/V.O. 配音另计）。

## 七、可灵实操步骤（图片→视频一条龙）

1. **登录**：klingai.com（网页版或 Windows 桌面端），画幅统一选 16:9。
2. **出 6 张基准板（文生图）**：图片生成 → 文生图 → 模型 IMAGE 3.0 → 复制《图片提示词.md》各 IMG 可复制提示词（去掉行首 `> `）→ 生成。顺序：先 3 人物定妆板 + 2 场景定调图，验收后出耳机道具板。
3. **出 19 张关键帧（图生图）**：图片生成 → 图生图（参考图/元素参考）→ 人物镜上传「人物定妆板 + 场景定调图」做多图参考 → 贴《分镜.md》该镜「冻结关键帧提示词」→ 生成。SHOT-005 / SHOT-018 各出两张（冻结帧 + 收尾帧）；SHOT-006 不出图（后期）。
4. **出 18 段视频（图生视频）**：视频生成 → 图生视频 → 模型 VIDEO 3.0（省钱用 3.0 Turbo）→ 上传对应关键帧 PNG 当首帧 → 复制《视频提示词.md》该 MOTION 可复制提示词 → 生成。SHOT-005 / SHOT-018 用「首尾帧」模式传两张；SHOT-006 不生成。
5. **成本**：25 张图 + 18 段视频远超免费档（每天约 66 积分≈一条带水印 720p），建议开会员（去水印 + 商用授权）。
6. **声音**：不在可灵做；对白/心声/旁白走后期配音 + 字幕合成，视频阶段只出画面。

## 十、即梦做声音（2026-10-06 改）

> 声音改为即梦实现（short-drama.json audio_generation=jimeng-native）。分工如下。

| 声音类型 | 即梦功能 | 操作 |
|---|---|---|
| 对白 5 句（王姨/老周/陈默） | 原生音频 / 对口型 | 图生视频时开原生音频，台词写进提示词选音色；或出片后走「对口型」贴音频 |
| 心声 1 句（老周「这小子…」） | 配音（干声） | 即梦配音出干声，后期贴耳；画面内老周不开口，**不走对口型** |
| V.O. 3 段（陈默旁白） | 配音（干声） | 即梦配音出干声，后期贴；画面不开口 |
| 环境声/音效（锅气、车铃、麻将、街声、面落锅） | 原生音频/音效 | 图生视频开原生音频，或即梦音效功能 |
| 死寂段（音轨全空） | —（即梦做不出"静"） | 后期剪映静音轨 |
| 心声双轨字幕（左轨嘴上/右轨心声） | — | 后期剪映 |
| 面落锅声桥、环境声句尾压低 | — | 后期剪映混音 |

- 音色锁定：可把之前 TTS 试音选定的片段上传给即梦「音色参考/克隆」锁定陈默/王姨/老周音色（创作者自有试音，授权无碍）。
- 音色对应：陈默→男声低沉/沉稳；王姨→女声；老周→男声沉稳（即梦自带 60 语种音色库）。
- 即梦对口型限制：单次音频约 36 秒、建议 MP3/M4A；正脸清晰、光线均匀的图口型最稳（侧脸镜如 SHOT-018 慎用对口型）。
